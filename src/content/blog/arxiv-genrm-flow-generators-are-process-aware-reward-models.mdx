## The Gap

Aligning diffusion and flow-matching video generation models with human aesthetic, motion, and temporal preferences is the primary bottleneck in generative media. In text models, reinforcement learning from human feedback (RLHF) utilizes scalar reward models (RMs). However, directly transplanting reward modeling to continuous video synthesis creates severe structural problems:

1. **The VLM Representation Paradigm (Pixel Space)**: Existing approaches (e.g., VideoAlign) decode generated noisy latents into pixel frames via a Variational Autoencoder (VAE) and feed them to an external Vision-Language Model (e.g., Qwen3-VL).  
   *The Breakdown*: VAE decoding fundamentally fails in high-noise regimes ($t \in [0.8, 1.0]$). As a consequence, VLM rewards can only be computed at the very final generation steps, leaving the critical **early-stage global composition and gross motion dynamics completely unsupervised**.
2. **The Auxiliary Scorer Paradigm (Feature Space)**: Other frameworks (e.g., PAVRM) freeze generator backbones and train separate classification or regression heads on intermediate features.  
   *The Breakdown*: This places scoring in a disjoint parameter space. Parametric divergence between the scoring head and the generator leads to severe out-of-distribution hallucinations and reward hacking during online reinforcement learning.
3. **The Core Paradox**: The generator's most potent capability—**predicting continuous vector velocity fields and denoising high-dimensional latents**—is entirely discarded during evaluation.

```
                    THE TRADITIONAL VIDEO REWARD PARADOX

  [Paradigm A: External VLM Scorer]
  Noisy Latent x_t ──> VAE Decoder ──> Collapses at high noise! (Only works at t ≈ 0)
                                   ──> External VLM Evaluator (Expensive, slow, disjoint)

  [Paradigm B: Auxiliary Feature Head]
  Noisy Latent x_t ──> Frozen DiT Backbone ──> Separate Regression Head (Parametric Drift!)

  [The Root Question]:
  Why train separate networks when the generator already knows how to denoise velocity fields?
```

## The Increment

**One sentence**: The authors present **GenRM-Flow**, proving mathematically that under KL-constrained preference optimization, an aligned flow-matching generator's own **relative difference in velocity-prediction error** acts as an exact, native process reward model in latent space, eliminating auxiliary networks, VAE decoding, and external VLM scorers.

```
                   GENRM-FLOW: GENERATION AS PROCESS REWARD

  Input Prompt c + Video Latent Trajectory x_t
       │
       ▼
  Run identical forward pass on:
  1. Base Reference Policy:  v_{θ_ref}(x_t, t, c)  ──> Loss: L_{ref} = || v_{θ_ref} - u_t ||^2
  2. Preference-Tuned Model: v_{θ^★}(x_t, t, c)    ──> Loss: L_{θ^★} = || v_{θ^★} - u_t ||^2
       │
       ▼
  [Exact Latent Process Reward]:
  r_t(x_t, c) = β * [ L_{ref}(x_t, c) - L_{θ^★}(x_t, c) ]
       │
       ├──> Lower error in tuned model? ──> Positive reward for human preference!
       ├──> Evaluates directly in continuous latent space across ALL timesteps t ∈ [0, 1]!
       └──> NO auxiliary reward head, NO pixel VAE decoding, ZERO parametric drift.
```

## Core Framework & Mechanisms

### 1. Mathematical Equivalence: From KL Optimal Policy to Velocity Error
Consider continuous-time flow matching, interpolating clean latent $x_0$ and Gaussian noise $x_1 \sim \mathcal{N}(0, I)$:
$$x_t = (1 - t)x_0 + t x_1, \quad u_t(x_t | x_0) = x_1 - x_0, \quad t \in [0, 1]$$
The flow-matching velocity loss is $L_\theta(x_t, c) = \| v_\theta(x_t, t, c) - u_t(x_t | x_0) \|^2$. A known variational property of probability flows connects velocity loss to data log-likelihood:
$$-\log p_\theta(x_0 | c) \lesssim \mathbb{E}_{t, x_1} [ L_\theta(x_t, c) ] + \text{const}$$

Under KL-constrained offline preference optimization, any objective (DPO, IPO, RWR) targets the analytical optimal policy:
$$\pi^*(x|c) = \frac{1}{Z(c)} \pi_{\text{ref}}(x|c) \exp\left( \frac{R_D(x, c)}{\beta} \right)$$
Algebraically isolating the target preference reward $R_D(x, c)$:
$$R_D(x, c) = \beta \log \frac{\pi^*(x|c)}{\pi_{\text{ref}}(x|c)} + \beta \log Z(c)$$

Substituting the negative velocity error $-L_\theta$ as the tractable surrogate for log-likelihood, the empirical reward emerges deterministically:
$$\hat{r}(x, c; \theta^\star, \theta_{\text{ref}}) \approx \beta \mathbb{E}_{t, x_1} \left[ L_{\text{ref}}(x_t, c) - L_{\theta^\star}(x_t, c) \right] + \beta \log Z(c)$$

The preference score is simply the **denoising advantage**: if the aligned generator $\theta^\star$ predicts the vector field with smaller Euclidean error than the reference generator $\theta_{\text{ref}}$, the latent is structurally preferred!

```
                  UNIFIED REWARD EXTRACTION FROM OBJECTIVES

  Objective F             Family                Loss Formulation L_F(θ)
  ────────────────────────────────────────────────────────────────────────────────
  RWR (Reward Weighted)   Likelihood            E_{t,x_1} [ L_θ(x_w, t) ]
  IPO (Identity-Margin)   Non-saturating        E_{t,x_1} [ ( (L_ref - L_θ)_{x_w} - (L_ref - L_θ)_{x_l} - 1/(2τ) )^2 ]
  DPO (Bradley-Terry)     Contrastive           -E_{t,x_1} [ log σ( β [ (L_ref - L_θ)_{x_w} - (L_ref - L_θ)_{x_l} ] ) ]
  ────────────────────────────────────────────────────────────────────────────────
  All three objectives fundamentally calibrate the scalar discrepancy [L_ref - L_θ]
  into a calibrated preference ranking function!
```

### 2. Closed-Loop Process RL via FlowAWR
To drive online reinforcement learning, GenRM-Flow is integrated into Flow Advantage-Weighted Regression (FlowAWR):
1. **Rollout**: Policy $\theta_{\text{old}}$ rolls out $G$ sample trajectories conditioned on prompt $c$ using an ODE solver, yielding final latent $\hat{x}_0^{(i)}$.
2. **Intermediate Process Reward**: At sampled timestep $t$, forward-noise $\hat{x}_0^{(i)}$ into $x_t^{(i)}$ and compute the instantaneous velocity discrepancy:
   $$r_t(x_t^{(i)}, c) = \beta \left[ L_{\text{ref}}(x_t^{(i)}, \hat{x}_0^{(i)}, c) - L_{\theta^\star}(x_t^{(i)}, \hat{x}_0^{(i)}, c) \right]$$
3. **Group Softmax Normalization**: Neutralizes the intractable prompt-dependent partition function $\beta \log Z(c)$:
   $$\tilde{r}_t(x_t^{(i)}, c) = \frac{\exp(r_t(x_t^{(i)}, c))}{\sum_{j=1}^G \exp(r_t(x_t^{(j)}, c))}$$
4. **Rectified Velocity Update**: With advantage $A_t = G \tilde{r}_t - 1$, regress current velocity $v_\theta$ toward the advantage-weighted trajectory target.

## Practical Implications

1. **Elimination of the Multi-Model Video Alignment Stack**: Teams fine-tuning open video models (e.g., Wan2.1, LTX-Video, CogVideoX) no longer need to stand up separate VLM inference endpoints or train auxiliary discriminator heads. The generator's own LoRA checkpoint serves simultaneously as the production generator and the RL process judge.
2. **True Full-Horizon Process Rewards**: Because flow-matching velocity loss is well-defined for all continuous timesteps $t \in [0, 1]$, reward credit assignment can guide early trajectory layouts, eliminating the "late-stage-only" bias of pixel reward models.
3. **Zero Parametric Divergence**: By evaluating rewards directly in the identical latent representation space of the base DiT, GenRM-Flow completely circumvents the out-of-distribution adversarial exploits that routinely derail video RLHF.

## 核心痛点：视频偏好对齐中“奖励模型外挂”的结构性悖论

当前文本到视频（T2V）生成模型（如 Wan2.1、Sora、Kling）在画面细节上已达到极高清晰度，生成管线的核心矛盾随之转移至**人类偏好对齐（Preference Alignment）**——即如何确保生成的视频在镜头流畅度、大幅度动作真实性、解剖学结构合理性以及美学构图上符合人类偏好。

在现有的视频人类偏好强化学习（RLHF / FlowAWR）中，核心枢纽是**奖励模型（Reward Model, RM）**。然而，当前业界在构建视频奖励模型时，陷入了两大固有范式的结构性困局：
1. **外挂 VLM 像素打分范式（如 VideoAlign）**：将生成器生成的加噪隐变量 Latent 通过变分自编码器（VAE）解码为 RGB 像素视频，再送入外部大视觉语言模型（如 Qwen3-VL）评分。  
   *致命痛点*：VAE 解码在**高噪声区间（$t \in [0.8, 1.0]$）完全崩溃**，根本无法还原有效像素。这导致外挂 VLM 只能在生成的最后几步（低噪区）提供反馈，而决定全片构图运镜与宏观动作轨迹的关键**前序阶段彻底处于无监督盲区**。
2. **外置辅助打分头范式（如 PAVRM）**：冻结视频生成器的主干网络，在其浅层特征上训练额外的判别分类头。  
   *致命痛点*：这使得奖励计算被隔离在脱节的独立参数空间中。打分头与生成器之间的参数表征漂移，会在强化学习在线采样阶段引发灾难性的对抗作弊（Reward Hacking）。
3. **终极悖论**：视频生成模型本身最核心、最强大的能力——**在连续时间场预测向量流场速度（Velocity）并逐步去噪**——在评价打分阶段被彻底弃用！

```
                    传统视频偏好对齐的割裂式管线

  【范式 A：外挂 VLM 像素级评分】
  加噪隐变量 x_t ──> VAE 图像解码 ──> 高噪区无法解码崩溃！(仅 t ≈ 0 有效)
                                  ──> 外部 VLM 打分 (推理成本高昂、动作理解迟钝)

  【范式 B：外置辅助特征打分头】
  加噪隐变量 x_t ──> 冻结 DiT 主干 ──> 外挂回归预测头 (参数空间漂移，极易奖励作弊)

  【根源命题】：
  流匹配生成器本身就精通全过程去噪速度预测，为何弃用其本体能力而舍近求远？
```

## 核心机制与数学推导

### 1. 严格数学等价性推导
在连续时间流匹配（Flow Matching）中，将真实隐变量 $x_0$ 与标准高斯噪声 $x_1 \sim \mathcal{N}(0, I)$ 进行线性插值：
$$x_t = (1 - t)x_0 + t x_1, \quad u_t(x_t | x_0) = x_1 - x_0, \quad t \in [0, 1]$$
流匹配的目标是学习向量场 $v_\theta(x_t, t, c)$ 以拟合真实速度 $u_t$：$L_\theta(x_t, c) = \| v_\theta(x_t, t, c) - u_t(x_t | x_0) \|^2$。基于概率流常微分方程的变分下界，速度预测均方误差与数据边际对数似然紧密绑定：
$$-\log p_\theta(x_0 | c) \lesssim \mathbb{E}_{t, x_1} [ L_\theta(x_t, c) ] + \text{const}$$

另一方面，在离线偏好优化（如 DPO、IPO、RWR）的数学框架下，所有损失函数本质上都在引导模型逼近 KL 约束下的理论最优策略：
$$\pi^*(x|c) = \frac{1}{Z(c)} \pi_{\text{ref}}(x|c) \exp\left( \frac{R_D(x, c)}{\beta} \right)$$
对该解析解两边取对数并整理出人类偏好奖励项 $R_D(x, c)$：
$$R_D(x, c) = \beta \log \frac{\pi^*(x|c)}{\pi_{\text{ref}}(x|c)} + \beta \log Z(c)$$

将流匹配速度误差代理代入对数似然差，经验过程奖励公式自然显现：
$$\hat{r}(x, c; \theta^\star, \theta_{\text{ref}}) \approx \beta \mathbb{E}_{t, x_1} \left[ L_{\text{ref}}(x_t, c) - L_{\theta^\star}(x_t, c) \right] + \beta \log Z(c)$$

物理含义极其优美直接：**若偏好微调后的模型 $\theta^\star$ 预测速度的误差显著低于未微调的参考模型 $\theta_{\text{ref}}$，则说明该生成片段更加契合人类偏好所驱动的流场偏移，应赋予正向奖励。**

```
                  三大偏好优化算法在流匹配下的统一读出

  算法名称                算法流派              流匹配损失函数 L_F(θ)
  ────────────────────────────────────────────────────────────────────────────────
  RWR (奖励加权回归)      无偏似然流派          E_{t,x_1} [ L_θ(x_w, t) ]
  IPO (恒等边际对比)      非饱和对比流派        E_{t,x_1} [ ( (L_ref - L_θ)_{x_w} - (L_ref - L_θ)_{x_l} - 1/(2τ) )^2 ]
  DPO (Bradley-Terry)     经典饱和对比流派      -E_{t,x_1} [ log σ( β [ (L_ref - L_θ)_{x_w} - (L_ref - L_θ)_{x_l} ] ) ]
  ────────────────────────────────────────────────────────────────────────────────
  三者在收敛极限下，均驱使模型去噪速度差 [L_ref - L_θ] 演变为严格校准的奖励打分器！
```

### 2. 基于 FlowAWR 的全时序过程强化学习
为将隐空间过程奖励转化为生成提升，作者将其深度嵌合入流匹配优势加权回归算法（FlowAWR）：
1. **组采样生成**：当前策略 $\theta_{\text{old}}$ 基于提示词 $c$ 采样 $G$ 条完整视频轨迹，终态隐变量记为 $\hat{x}_0^{(i)}$。
2. **瞬时过程奖励抽取**：在任意加噪时刻 $t$，将终态加噪后代入冻结的对齐 LoRA 权重与基座权重中计算瞬时速度差：
   $$r_t(x_t^{(i)}, c) = \beta \left[ L_{\text{ref}}(x_t^{(i)}, \hat{x}_0^{(i)}, c) - L_{\theta^\star}(x_t^{(i)}, \hat{x}_0^{(i)}, c) \right]$$
3. **组内 Softmax 归一化**：通过组内 Softmax 处理彻底消除难以计算的提示词偏置常数 $\beta \log Z(c)$：
   $$\tilde{r}_t(x_t^{(i)}, c) = \frac{\exp(r_t(x_t^{(i)}, c))}{\sum_{j=1}^G \exp(r_t(x_t^{(j)}, c))}$$
4. **流场速度矫正**：以优势度 $A_t = G \tilde{r}_t - 1$ 加权修正 ODE 速度场，实现无需像素反传的极速在线对齐。

## 实践启示与工程落地

1. **大幅削减视频强化学习的显存与部署成本**：工业界在做视频对齐时，以往需要单独部署一套包含视觉编码器、多模态大模型和判别头的庞大服务器集群。GenRM-Flow 实现了“模型即判官”，仅需加载一份 LoRA 权重即可在同一套 DiT 计算图内完成打分。
2. **实现真・全时段过程奖励塑造**：流匹配速度误差天然贯穿扩散逆过程的任意实数时刻 $t \in [0, 1]$，算法工程师可对每一帧、每一个去噪步进行精细化信用分配，彻底解放了此前只能基于最终生成帧进行黑盒奖励的局限。
3. **零表征偏移的天然稳定性**：所有打分完全发生于生成模型自身的隐变量表示空间内，彻底消除了判别模型与生成模型之间的领域漂移（Domain Shift），为未来超大规模视频强化学习在线探索奠定了极其稳固的基石。
