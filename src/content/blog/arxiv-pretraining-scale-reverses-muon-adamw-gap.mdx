## The Gap

The optimizer landscape for Large Language Model (LLM) pretraining has recently been disrupted by **Muon** (Momentumized Orthogonalized Newton-Schulz updates). By constraining parameter updates to the Stiefel manifold of orthogonal matrices, Muon consistently achieves faster convergence and lower base pretraining loss compared to AdamW at identical compute budgets.

However, modern foundation models are almost never deployed as raw base checkpoints; they must undergo **post-training** (Supervised Fine-Tuning, RLHF, and task adaptation). This introduces a critical open question: **Does Muon's pretraining loss advantage translate into superior downstream task performance, or does it degrade the learning-forgetting trade-off?**

Prior empirical investigations suffered from significant blind spots:
1. **Conflating Base Loss with Downstream Retention**: Machine learning practitioners have long treated pretraining validation loss as an infallible proxy for downstream capability.
2. **Ignoring Pretraining Scale Interactions**: Comparisons between Muon and AdamW were predominantly conducted on small token budgets (sub-10B tokens), overlooking how scaling laws alter optimization dynamics.
3. **Absence of a Theoretical Mechanism**: Why would an optimizer that produces lower cross-entropy loss perform *worse* when fine-tuned on new tasks?

```
                 THE MUON VS ADAMW PRETRAINING PARADOX

  Pretraining Phase (Minimizing Base Cross-Entropy Loss):
  Muon  ───> Consistently lower Loss than AdamW across ALL data scales! ✓
  AdamW ───> Slower convergence, higher training loss.

  Post-Training Phase (Fine-Tuning on Downstream Tasks):
  Small Data Budget (< 5B tokens):
  - Muon dominates AdamW downstream (Better task adaptation & retention).

  Large Data Budget (> 10B-30B tokens):
  - THE REVERSAL: AdamW systematically beats Muon after fine-tuning!
  - As model scale increases, AdamW overtakes Muon at progressively
    smaller token-to-parameter ratios.
```

## The Increment

**One sentence**: The authors discover that scaling pretraining data reverses the downstream Muon–AdamW fine-tuning gap, and explain this phenomenon through the **Margin-to-Spread Ratio (MSR)**—proving that while Muon creates sharper logit separation at low budgets, AdamW builds broader, more noise-resilient margin distributions at scale.

```
                    THE MARGIN-TO-SPREAD RATIO (MSR)

                  Correct Logit (y*)
                         │
                         ▼
  ───────────────────────┬────────────────────────────────────────
                         │ <────── Margin h ──────>
                         │
        Wrong Logits Distribution: Spread κ = std(wrong logits)
             ┌───────────┴───────────┐
             │   ░░░░░░░░░░░░░░░░    │
  ───────────┴───────────────────────┴────────────────────────────

  MSR = h / κ = (Distance to incorrect mean) / (Spread of incorrect logits)

  - High MSR: The correct prediction is isolated far beyond the noise floor.
              Robust to output distribution perturbations during SFT.
  - Small Data Scale:  MSR(Muon) > MSR(AdamW)  ==> Muon wins fine-tuning.
  - Large Data Scale:  MSR(AdamW) > MSR(Muon)  ==> AdamW wins fine-tuning!
```

## The Anatomy

### 1. The Learning–Forgetting Frontier

To rigorously evaluate fine-tuning behavior, the authors train multiple OLMo architectures (from 30M to 300M parameters) across pretraining token budgets ranging from 2.4B to 38.4B tokens on the DCLM corpus, followed by extensive hyperparameter grid sweeps during fine-tuning on StackMathQA.

The evaluation measures the Pareto frontier between:
- **Target Task Learning Loss**: How effectively the model learns new downstream capabilities.
- **Pretraining Forgetting Loss**: How severely the model degrades on its original pretraining distribution.

Across every model size, as pretraining tokens scale:
1. At small token budgets (e.g., 2.4B tokens for OLMo-60M), the Muon frontier strictly dominates AdamW.
2. At larger token budgets (e.g., 9.6B, 19.2B, and 38.4B tokens), the frontier **reverses**: AdamW retains more pretraining knowledge for any given level of fine-tuning accuracy.
3. Crucially, as model parameter size grows (from 30M to 300M), the crossover point shifts to **smaller token-to-parameter ratios**, indicating that large frontier models are especially prone to this reversal.

### 2. Theoretical Mechanism: The Margin-to-Spread Ratio (MSR)

Fine-tuning can mathematically be framed as an adversarial perturbation $\delta$ applied to the pre-softmax output logits $s(x) = W^\top x$. A base model is resilient to forgetting if its correct predictions can tolerate large output shifts before the argmax ranking flips.

To quantify this tolerance, the authors define the **Margin-to-Spread Ratio (MSR)**:
$$\rho = \frac{h}{\kappa}$$
where:
- $h = s_{y^*} - \frac{1}{|\mathcal{V}| - 1} \sum_{j \ne y^*} s_j$ is the **mean margin** (distance between the correct logit $y^*$ and the centroid of incorrect logits).
- $\kappa = \sqrt{\frac{1}{|\mathcal{V}| - 1} \sum_{j \ne y^*} (s_j - \bar{s}_{\text{wrong}})^2}$ is the **spread** (standard deviation among incorrect logits).

A prediction with a large $h$ but an equally large $\kappa$ is fragile: an arbitrary small perturbation can easily push an outlying incorrect logit above $y^*$. True robustness requires maximizing margin $h$ while minimizing spread $\kappa$.

### 3. Formal Proof in Linear Associative Memory

To analyze why optimizers diverge, the authors study a linear associative memory retrieving $N$ key-value facts $(u_i, v_i) \in \mathbb{R}^d \times \mathbb{R}^d$ parameterized by $W \in \mathbb{R}^{d \times d}$, with data budget ratio $\gamma = N/d$.

**Theorem 4.2 (Informal Summary)**:  
Under isotropic Gaussian facts, after an update from zero initialization, the ratio of Gradient Descent's (AdamW proxy) MSR to Muon's MSR satisfies:
$$\mathcal{R}(\gamma) = \frac{\rho_{\text{GD}}(\gamma)}{\rho_{\text{Muon}}(\gamma)} = \frac{1 + \frac{2}{\gamma}}{\sqrt{1 + \frac{1}{\gamma}}}$$
which is a **strictly increasing function of the data budget $\gamma$**.

- When data budget $\gamma$ is small, Muon's matrix-orthogonalization forces faster spectral alignment, yielding a higher MSR ($\mathcal{R} < 1$).
- As data budget $\gamma$ expands, Gradient Descent / AdamW accumulates coherent gradient signals along the signal subspace while isotropically diffusing noise across orthogonal directions, causing AdamW's MSR to surpass Muon ($\mathcal{R} > 1$).

## Quantitative Evaluation

### 1. MSR Crossover in Language Models

Evaluating pretrained OLMo models on held-out DCLM text reveals that the empirical MSR tracks the downstream fine-tuning gap with high fidelity:

| Model Scale | Pretrain Tokens | Muon MSR ($\rho$) | AdamW MSR ($\rho$) | Dominant Optimizer (MSR) | Downstream Fine-Tuning Winner |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **OLMo-60M** | 2.4B | **2.84** | 2.51 | **Muon (+13.1%)** | **Muon** |
| | 4.8B | **3.22** | 3.15 | **Muon (+2.2%)** | **Muon** |
| | 9.6B | 3.65 | **3.82** | **AdamW (+4.7%)** | **AdamW** |
| | 19.2B | 4.08 | **4.45** | **AdamW (+9.1%)** | **AdamW** |
| | 38.4B | 4.31 | **4.92** | **AdamW (+14.2%)** | **AdamW** |
| **OLMo-100M** | 4.8B | **3.45** | 3.38 | **Muon (+2.1%)** | **Muon** |
| | 9.6B | 3.88 | **4.09** | **AdamW (+5.4%)** | **AdamW** |
| | 19.2B | 4.25 | **4.76** | **AdamW (+12.0%)** | **AdamW** |
| **OLMo-150M** | 4.8B | 3.61 | **3.74** | **AdamW (+3.6%)** | **AdamW** |
| | 19.2B | 4.40 | **5.08** | **AdamW (+15.5%)** | **AdamW** |

*Key Findings*:
1. **The Reversal is Robust Across Scales**: In every tested model, Muon leads in MSR at low data volumes, but AdamW overtakes it once token scale increases.
2. **Larger Models Flip Sooner**: For OLMo-60M, the crossover occurs around ~7B tokens (token:param ratio ~115:1). For OLMo-150M, AdamW already leads at 4.8B tokens (token:param ratio ~32:1).
3. **Overfitting to Cross-Entropy**: Muon's orthogonalization forces singular values to be uniform, which aggressively squashes cross-entropy loss by sharpening logits, but leaves the underlying representation hypersensitive to the directional weight updates made during fine-tuning.

---

## Key Takeaways

1. **Pretraining Loss is Not King**: An optimizer that achieves a lower validation loss during pretraining does not necessarily yield a better foundation model for downstream deployment.
2. **Scale Changes Optimization Geometry**: Muon's superiority in small-scale benchmarks (like Speedrun or sub-10B training) cannot be extrapolated blindly to multi-trillion-token frontier training runs.
3. **The Hybrid Compromise**: Because Muon converges rapidly in early training while AdamW builds more robust asymptotic representations, hybrid schedules—e.g., pretraining with Muon early on and transitioning to AdamW or annealing with AdamW-like momentum—represent a highly promising frontier.

## 核心痛点与背景

近年来，大语言模型（LLM）预训练优化算法领域涌现出了一匹黑马——**Muon 优化器**（基于动量正交化 Newton-Schulz 迭代）。通过将参数矩阵更新严格约束在正交 Stiefel 流形上，Muon 在同等算力预算下能够比业界基石 AdamW 更快地压低预训练交叉熵损失（Pretraining Loss）。

然而，现代基座大模型极少直接用于生产，必须经历**后训练阶段**（SFT 监督微调、RLHF 强化学习与下游领域适配）。这带来了一个极为关键且悬而未决的核心命题：**Muon 在预训练 Loss 上的显著优势，能否顺利迁移至下游微调任务？它在“新知识学习-旧知识遗忘”（Learning–Forgetting Trade-off）博弈中究竟表现如何？**

现有的大模型实证研究存在显著的认知盲区：
1. **唯“预训练 Loss”论的惯性误区**：学术界与工程界长期将预训练验证集 Loss 视为下游能力的唯一代理指标，默认 Loss 越低微调效果越好。
2. **数据规模盲区**：以往针对 Muon 的对比多数停留在几十亿 Token（Sub-10B）的小规模试验中，未能探明扩展规律（Scaling Law）对优化动力学的影响。
3. **机理解释的缺失**：为什么一个能把交叉熵损失降得更低的优化器，在微调时反而可能更容易发生灾难性遗忘？

```
                 MUON 与 ADAMW 的预训练反转悖论

  预训练阶段（优化目标：最小化基础 Cross-Entropy Loss）：
  Muon  ───> 在所有数据尺度下，Loss 均系统性低于 AdamW！✓
  AdamW ───> 收敛速度较慢，预训练 Loss 相对更高。

  后训练微调阶段（下游任务 SFT 适配）：
  小数据预算规模（< 5B Tokens）：
  - Muon 在下游微调任务中占据优势（收敛快、遗忘少）。

  大数据预算规模（> 10B-30B Tokens）：
  - 发生惊人反转：AdamW 微调后的综合性能全面反超 Muon！
  - 随着模型参数量增大，AdamW 实现反超所需的“Token-参数比”越来越小！
```

## 核心贡献与创新

**一句话总结**：CMU 团队发现并证明了**预训练数据规模会反转 Muon 与 AdamW 的微调性能差距**，并提出**边际展宽比（Margin-to-Spread Ratio, MSR）**这一全新几何指标，在数学上证明了 Muon 在大规模训练下产生过于陡峭脆弱的 Logit 分布，而 AdamW 则构建了对后训练扰动更为宽容的鲁棒决策边界。

```
                    边际展宽比（Margin-to-Spread Ratio, MSR）

                   正确预测 Logit (y*)
                          │
                          ▼
  ────────────────────────┼───────────────────────────────────────
                          │ <────── 边际间隔 h ──────>
                          │
          错误 Logit 经验分布: 展宽离散度 κ = std(wrong logits)
              ┌───────────┴───────────┐
              │   ░░░░░░░░░░░░░░░░    │
  ────────────┴───────────────────────┴───────────────────────────

  MSR = h / κ = (正确 Logit 距离错误均值的距离) / (错误 Logit 自身的标准差)

  - MSR 越大：正确预测在几何上被隔绝在噪声基线之上，抗微调扰动能力越强。
  - 小数据规模时：  MSR(Muon) > MSR(AdamW)  ==> Muon 微调表现领先。
  - 大数据规模时：  MSR(AdamW) > MSR(Muon)  ==> AdamW 微调表现反超！
```

## 核心技术实现

### 1. 学习-遗忘帕累托前沿（Learning–Forgetting Frontier）

为了系统解耦下游微调质量，研究团队基于 DCLM 高质量语料，在不同预训练 Token 预算（2.4B 至 38.4B）下系统训练了从 30M 到 300M 多种尺寸的 OLMo 模型，并在 StackMathQA 上对微调超参数进行了全网格搜索扫描。

评估通过绘制帕累托前沿（Pareto Frontier）综合衡量：
- **微调任务损失**：模型吸收新任务专业能力的好坏。
- **预训练遗忘损失**：模型在原有基础语言分布上的遗忘程度。

实证结果揭示出严格的反转轨迹：
1. 在小数据预算下（如 OLMo-60M 训练 2.4B Tokens），Muon 的帕累托前沿绝对支配 AdamW。
2. 随着数据扩展至 9.6B、19.2B 与 38.4B，**前沿发生系统性反转**：在达成相同微调精度的情况下，AdamW 模型的遗忘程度显著低于 Muon。
3. 模型的参数量越大（从 30M 扩展到 300M），AdamW 反超 Muon 所需的“Token-参数比”门槛越低，表明大模型在海量预训练中更容易受到该反转效应的影响。

### 2. 理论分析基石：边际展宽比（MSR）

从表征几何的角度来看，微调过程本质上是对预训练模型最后一层输出 Logit 实施了方向性的扰动 $\delta$。如果一个基座模型的正确预测 Logit 能够承受更大的扰动而不发生 Top-1 翻转，它在微调时就越不容易遗忘。

作者据此形式化提出了**边际展宽比（Margin-to-Spread Ratio, MSR）**：
$$\rho = \frac{h}{\kappa}$$
其中：
- $h = s_{y^*} - \frac{1}{|\mathcal{V}| - 1} \sum_{j \ne y^*} s_j$ 为**平均边际（Margin）**，衡量正确类别 Logit 超出所有错误类别均值的绝对距离。
- $\kappa = \sqrt{\frac{1}{|\mathcal{V}| - 1} \sum_{j \ne y^*} (s_j - \bar{s}_{\text{wrong}})^2}$ 为**展宽离散度（Spread）**，衡量所有错误类别 Logit 之间的波动方差。

若仅追求边际 $h$ 极大，但错误类别本身的离散度 $\kappa$ 同样巨大，那么只要微调时输出受到微小扰动，某个位于极值长尾的错误 Logit 就会瞬间反超 $y^*$。高 MSR 才是抗遗忘的本质充要条件。

### 3. 线性联想记忆模型的数学证明

为了深入分析两者差异的数学成因，研究团队在恢复 $N$ 个高斯键值对事实 $(u_i, v_i) \in \mathbb{R}^d \times \mathbb{R}^d$ 的线性联想记忆（Linear Associative Memory）模型中进行了严格推导，设定数据预算密度为 $\gamma = N/d$。

**定理 4.2 核心推论**：  
在零初始化单步更新下，梯度下降（GD，对应 AdamW）与 Muon 的 MSR 之比满足：
$$\mathcal{R}(\gamma) = \frac{\rho_{\text{GD}}(\gamma)}{\rho_{\text{Muon}}(\gamma)} = \frac{1 + \frac{2}{\gamma}}{\sqrt{1 + \frac{1}{\gamma}}}$$
该比例是数据预算 $\gamma$ 的**严格单调递增函数**。

- 当 $\gamma$ 较小时，Muon 的奇异值正交归一化迫使特征快速对齐，此时 $\mathcal{R} < 1$，Muon MSR 占优。
- 随着预训练数据规模 $\gamma$ 增加，梯度下降在信号子空间稳定积累能量，同时将噪声各向同性稀释，导致 $\mathcal{R} > 1$，AdamW 的 MSR 实现不可逆的反超。

## 实验结果与深度分析

### 1. 真实语言模型中的 MSR 反转验证

在 DCLM 验证集上对不同规格的预训练 OLMo 模型进行逐 Token MSR 评测，所得数据与下游微调反转完全对齐：

| 模型尺寸 | 预训练 Token 规模 | Muon MSR ($\rho$) | AdamW MSR ($\rho$) | MSR 领先者 | 最终下游微调胜者 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **OLMo-60M** | 2.4B | **2.84** | 2.51 | **Muon (+13.1%)** | **Muon** |
| | 4.8B | **3.22** | 3.15 | **Muon (+2.2%)** | **Muon** |
| | 9.6B | 3.65 | **3.82** | **AdamW (+4.7%)** | **AdamW** |
| | 19.2B | 4.08 | **4.45** | **AdamW (+9.1%)** | **AdamW** |
| | 38.4B | 4.31 | **4.92** | **AdamW (+14.2%)** | **AdamW** |
| **OLMo-100M** | 4.8B | **3.45** | 3.38 | **Muon (+2.1%)** | **Muon** |
| | 9.6B | 3.88 | **4.09** | **AdamW (+5.4%)** | **AdamW** |
| | 19.2B | 4.25 | **4.76** | **AdamW (+12.0%)** | **AdamW** |
| **OLMo-150M** | 4.8B | 3.61 | **3.74** | **AdamW (+3.6%)** | **AdamW** |
| | 19.2B | 4.40 | **5.08** | **AdamW (+15.5%)** | **AdamW** |

*深度实证结论*：
1. **反转效应具有高度普适性**：在所有测算模型中，只要预训练 Token 量越过临界点，AdamW 的 MSR 与微调表现均双双反超 Muon。
2. **大尺寸模型反转发生得更早**：对于 60M 模型，反转点出现在约 7B Tokens（Token:参数比约为 115:1）；而对 150M 模型，在仅 4.8B Tokens 时（Token:参数比 32:1）AdamW 便已确立领先优势。
3. **针对交叉熵损失的“过度拟合”**：Muon 的正交化更新强制拉平了权重的奇异值谱，这一机制在数值上能极其暴烈地压低交叉熵，但其副产物是形成了极其陡峭狭窄的局部极小值，微调阶段的参数微调极易破坏这种脆弱平衡。

## 启示与实践意义

1. **破除预训练 Loss 的绝对迷信**：训练过程中的验证集 Loss 并不等同于最终交付模型的商用表现，优化器的泛化拓扑与抗微调扰动能力应当纳入基座评估体系。
2. **警惕小算力评测向万亿大模型的“认知漂移”**：在学术界几十亿 Token 的快速刷榜（如 Speedrun）中表现亮眼的技巧，切忌未经 Scaling 检验便直接应用于百亿/千亿级工业长训。
3. **混合调度优化器的演进前景**：鉴于 Muon 在前期拥有无可比拟的快速收敛爆发力，而 AdamW 在后期具备更宽广厚实的几何鲁棒性，未来基座预训练中采用“前期 Muon 突击 + 后期切换至 AdamW 稳健收敛”的混合退火策略或将成为全新标准。
