## The Gap

Reinforcement Learning (RL) post-training has driven major breakthroughs in frontier reasoning models (e.g., OpenAI o-series, DeepSeek-R1, Kimi k1.5). In post-training, an already capable pretrained **base model** $\pi_{\text{base}}$ is adapted using reward feedback. The core promise is that the base model already possesses high **response coverage**—it can generate optimal answers with non-trivial probability—and RL should amplify this capability.

However, despite massive engineering investments in algorithms like PPO (Proximal Policy Optimization) and GRPO (Group Relative Policy Optimization), the field suffers from a lack of foundational theory:
1. **The Coverage Puzzle**: In practice, policy optimization frequently encounters prolonged training plateaus and catastrophic capability collapse. Why do algorithms that optimize expected reward stall, even when the base model starts with favorable coverage of correct answers?
2. **The Inefficacy of Static KL Regularization**: Practitioners routinely add a Kullback-Leibler (KL) penalty against the base model $\pi_{\text{base}}$:
   $$\mathcal{J}_\eta(\pi_\theta) := \mathcal{J}(\pi_\theta) - \frac{1}{\eta} D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{base}})$$
   If $\eta$ is large (weak regularization), the policy quickly drifts and destabilizes. If $\eta$ is small (strong regularization), the policy is pinned to the base model and fails to reach optimality.
3. **The Disconnect in Algorithmic Recipes**: Why do leading open recipes disagree on fundamental choices—such as clipping versus KL regularization, policy gradient versus squared-loss objectives, or reference resets?

```
                    THE COVERAGE COLLAPSE PHENOMENON

  Pretrained Base Model π_base: Has good response coverage (C_base ≤ 6)
  
  [Standard REINFORCE / PPO / GRPO with fixed base reference π_base]:
  Iterate t=0 ──> Iterate t=100 ──> Iterate t=1,000 ...
  Expected Reward J(π_t) rises monotonically: 0.2 ──> 0.5 ──> 0.8
  
  BUT Probability of Optimal Response π_t(Y^*_x | x) crashes!
  Coverage Metric: C_{π_t} explodes from 6 to exp(Ω(1 / √ε))!
  
  Result: Optimal solutions become exponentially rare to sample.
          Gradient signals vanish into an exponential plateau.
          Optimization stalls completely despite good initial coverage!
```

## The Increment

**One sentence**: The authors uncover **coverage collapse**—proving that standard policy gradients drive optimal response probabilities to near zero even under exact gradients and static KL penalties—and prove that **periodically resetting the KL reference to the active policy** (formalized as Approximate Policy Mirror Descent / APMD) guarantees **coverage preservation** and polynomial convergence, theoretically validating the design of models like Kimi k1.5.

```
                  APMD: MITIGATING COVERAGE COLLAPSE VIA REFERENCE RESETS

  Outer Loop t = 0, 1, 2, ... , T:
  
  1. REFERENCE RESET:
     Anchor KL penalty to CURRENT policy π_t (NOT static π_base!):
     Target: π^*_{η,t}(y|x) ∝ π_t(y|x) · exp(η · r(x, y))
  
  2. INNER SOLVE:
     Solve KL-regularized subproblem: D_KL(π_{t+1} || π^*_{η,t}) ≤ ε_in
     ├── Enables STRONG local regularization (large 1/η) -> Subproblem is easy to solve!
     └── Resets allow GLOBAL progression -> Sublinear mirror descent convergence!
  
  Guaranteed Outcome (Theorem 3.1):
  For all iterates t: π_t(Y^*_x | x) ≥ 0.5 · π_base(Y^*_x | x)  [Coverage is Preserved!]
  Final Suboptimality: J^* - J(π_T) ≤ log(2 C_base) / (η T)
```

## Core Framework & Mechanisms

### 1. Mathematical Formalization of Response Coverage
Let prompt $x \sim \mu$, and $Y^*_x := \{ y \in \mathcal{Y} : r(x, y) = \max_{y'} r(x, y') \}$ be the set of optimal responses. The **response coverage** of a policy $\pi$ is:
$$\mathcal{C}_\pi := \mathbb{E}_{x \sim \mu} \left[ \frac{1}{\pi(Y^*_x | x)} \right]$$
Small $\mathcal{C}_\pi$ means fewer samples are required to observe an optimal response (e.g., Best-of-$N$ requires $N = \widetilde{\mathcal{O}}(\mathcal{C}_{\text{base}} / \varepsilon)$ samples).

### 2. Theorem 2.1: The Lower Bound on Coverage Collapse
The authors prove that standard policy gradients inherently destroy coverage:
> **Theorem 2.1 (Coverage Collapse in REINFORCE)**: Fix $\varepsilon \in (0, 1/64]$. There exists a bandit instance with base model $\mathcal{C}_{\text{base}} \le 6$ such that for any learning rate $\alpha \le 1/5$ and any static regularization parameter $\eta \in (0, \infty]$, REINFORCE produces an intermediate iterate $t < T$ where:
> $$\mathcal{C}_{\pi_t} = \exp\left( \Theta\left(\frac{1}{\sqrt{\varepsilon}}\right) \right), \quad \text{requiring } T = \Omega\left( \frac{\mathcal{C}_{\pi_t}}{\alpha \sqrt{\varepsilon}} \right) \text{ steps to converge.}$$

Because the RL objective is non-concave for softmax policies, the Łojasiewicz gradient inequality:
$$J^* - J(\pi_t) \le c \cdot \| \pi^* / \pi_t \|_\infty \cdot \| \nabla \mathcal{J}(\pi_t) \|$$
is throttled by $\| \pi^* / \pi_t \|_\infty$. When optimal actions are prematurely deprioritized, $\| \nabla \mathcal{J}(\pi_t) \| \to 0$ while the suboptimality gap remains massive, freezing the policy on an exponential plateau.

### 3. Approximate Policy Mirror Descent (APMD)
To prevent collapse, APMD updates the policy via sequential KL-regularized proximal targets:
$$\pi^*_{t,\eta} := \arg\max_{\pi} \mathbb{E}_\pi [r(x, y)] - \frac{1}{\eta} D_{\text{KL}}(\pi \parallel \pi_t) \implies \pi^*_{t,\eta}(y|x) \propto \pi_t(y|x) e^{\eta r(x, y)}$$

Key Theoretical Guarantees:
- **Coverage Preservation**: If each inner subproblem achieves error $D_{\text{KL}}(\pi_{t+1} \parallel \pi^*_{t,\eta}) \le \varepsilon_{\text{in}} := \frac{1}{64 \mathcal{C}_{\text{base}} T^2 \log(eT)}$, then with high probability:
  $$\pi_t(Y^*_x | x) \ge \frac{1}{2} \pi_{\text{base}}(Y^*_x | x), \quad \forall 0 \le t \le T$$
- **Global Sublinear Convergence**: The suboptimality gap shrinks monotonically as:
  $$J^* - J(\pi_T) \le \frac{\log(2 \mathcal{C}_{\text{base}})}{\eta T}$$

```
                           TAXONOMY OF POST-TRAINING ALGORITHMS

  Algorithm Family         Objective / Loss              Reference Scheme   Coverage Preserving?
  ─────────────────────────────────────────────────────────────────────────────────────────────
  Naïve REINFORCE          Policy gradient on J(π)       None               NO (Collapses exp.)
  Standard PPO / GRPO      Clipped ratio to π_base       Static π_base      NO (Plateaus)
  APMD-PPO / APMD-GRPO     KL-regularized proximal       Reset to π_t       YES (Theorem 3.1)
  Squared-Loss (Kimi k1.5) Implicit mirror descent       Implicit Reset     YES (Theorem 4.1)
```

## Empirical Validation & Algorithmic Implications

### 1. Validating Coverage Dynamics
In controlled experiments comparing REINFORCE against APMD on instances where $\mathcal{C}_{\text{base}} = 6$:
- In **REINFORCE with static base KL**, coverage $\mathcal{C}_{\pi_t}$ explodes from $10^1$ to over $10^4$ by step 1,500, stalling reward improvement in a prolonged plateau lasting over 8,000 gradient steps.
- In **APMD (with reference resets every $K=100$ steps)**, coverage $\mathcal{C}_{\pi_t}$ remains bounded below $10^1$ throughout training, smoothly ascending to $J^* = 1.0$ within 1,200 steps (an **$8\times$ optimization speedup**).

### 2. Theoretical Grounding for Kimi k1.5 Squared-Loss RL
A major contribution of Section 4 is establishing formal equivalence between APMD and the **squared-loss policy optimization** recently adopted in frontier reasoning models like Moonshot AI's Kimi k1.5:
$$\mathcal{L}_{\text{square}}(\theta) := \mathbb{E}_{x, y \sim \pi_t} \left[ \left( \log \pi_\theta(y|x) - \log \pi_t(y|x) - \eta A^{\pi_t}(x, y) \right)^2 \right]$$
The authors prove that minimizing this regression loss implicitly executes an APMD step with reference reset to $\pi_t$. Consequently, Kimi's squared-loss formulation is **fundamentally coverage-preserving**, explaining why it avoids the policy collapse that plagues standard PPO.

## Practical Implications

1. **Stop Anchoring KL Regularization to $\pi_{\text{base}}$**: Static base-model KL penalties do not prevent policy collapse. Modern RL post-training infrastructure should anchor KL regularization to the **current checkpoint $\pi_t$** (or update the reference periodically in an outer loop).
2. **Aggressive Regularization Becomes Viable**: With reference resets, engineers can safely crank up the regularization penalty $\frac{1}{\eta}$ without fearing under-optimization, making each inner gradient step far more stable and variance-reduced.
3. **Formal Justification for Regression-Based RL**: The mathematical convergence guarantees confirm that squared-loss objectives (regressing log-probabilities onto advantage targets) are not mere empirical heuristics, but theoretically grounded mirror descent implementations that preserve base model coverage.

## 核心痛点：后训练强化学习中的“覆盖度崩溃”谜题

以 OpenAI o-系列、DeepSeek-R1 以及月之暗面 Kimi k1.5 为代表的前沿大模型，其核心突破皆归功于**后训练强化学习（RL Post-Training）**。后训练的基本范式是：以经过海量预训练的基座模型 $\pi_{\text{base}}$ 为起点，利用可验证奖励（Verifiable Rewards）或人类偏好信号进一步微调。这一范式的核心假设是：**基座模型本身已经具备相当优秀的“响应覆盖度”（Response Coverage）**——即以非零概率能够采样出正确或最优的推理路径，RL 的目标仅仅是将这种潜能放大提炼。

然而，尽管工业界在 PPO 与 GRPO 的工程调优上投入巨大，算法理论却长期滞后于工程实践：
1. **优化停滞之谜**：在实际训练中，模型经常在某个奖励区间陷入长达数千步的漫长平台期（Reward Plateau），甚至突发崩溃。为什么在基座模型本身解题率尚可的前提下，优化器仍会停滞？
2. **静态基座 KL 惩罚的失效**：为防止模型偏离预训练知识，工业界广泛在目标函数中加入针对基座模型 $\pi_{\text{base}}$ 的 KL 正则惩罚：
   $$\mathcal{J}_\eta(\pi_\theta) := \mathcal{J}(\pi_\theta) - \frac{1}{\eta} D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{base}})$$
   然而这里存在一个无法调和的矛盾：若正则过弱（$\eta$ 很大），策略会迅速偏移导致数值不稳定；若正则过强（$\eta$ 很小），策略被牢牢焊死在基座模型周围，根本无法探索到全局最优解。
3. **算法流派的割裂**：为什么各家开源前沿模型在后训练核心算法上各执一词？（例如 DeepSeek 坚持纯策略梯度的 GRPO，而 Kimi 则采用均方误差平方损失回归）。

```
                     后训练中的“覆盖度崩溃”（Coverage Collapse）

  预训练基座模型 π_base：具备良好的响应覆盖度 (C_base ≤ 6)
  
  【采用固定基座参考 π_base 的常规 REINFORCE / PPO / GRPO】：
  训练步数迭代：t=0 ──> t=100 ──> t=1,000 ...
  期望奖励 J(π_t) 单调微幅上升：0.2 ──> 0.5 ──> 0.8
  
  然而：模型生成最优响应的采样概率 π_t(Y^*_x | x) 暴跌！
  覆盖度指标 C_{π_t} 从 6 爆炸式增长至 exp(Ω(1 / √ε))！
  
  后果：原本基座模型还能偶尔做对的题目，在训练中被彻底降权至极小概率。
        采样批次中再也遇不到正向奖励，策略梯度彻底归零，优化陷入死锁！
```

## 核心突破：参考策略重置与近似镜像下降（APMD）

**核心结论**：哈佛与微软理论团队在长达 141 页的研究中，首次从数学上严格刻画了**覆盖度崩溃（Coverage Collapse）**：证明了即使在精确梯度和静态 KL 正则下，标准策略梯度仍会使最优响应概率收缩至近乎为零；同时证明，**周期性将 KL 正则参考点重置为最新策略**（形式化为近似策略镜像下降 APMD），能够从根本上保证覆盖度留存（Coverage-Preserving）与多项式时间收敛，并为 Kimi k1.5 等工业界平方损失算法提供了首个全局收敛性理论保证。

```
                  APMD 架构：通过参考策略重置终结覆盖度崩溃

  外层循环迭代 t = 0, 1, 2, ... , T:
  
  1. 参考策略重置（Reference Reset）：
     将 KL 正则锚点直接切换至当前策略 π_t（而非冻结的静态 π_base！）：

  严格数学保证（定理 3.1）：
  在全训练周期内：π_t(Y^*_x | x) ≥ 0.5 · π_base(Y^*_x | x)  【覆盖度永不崩溃！】
  全局最优性差距：J^* - J(π_T) ≤ log(2 C_base) / (η T)

## 核心机制与数学推导

### 1. 响应覆盖度（Response Coverage）形式化定义
设输入提示词 $x \sim \mu$，定义 $Y^*_x := \{ y \in \mathcal{Y} : r(x, y) = \max_{y'} r(x, y') \}$ 为最优响应集合。策略 $\pi$ 的**响应覆盖度**定义为采样到最优解的期望倒数：
$$\mathcal{C}_\pi := \mathbb{E}_{x \sim \mu} \left[ \frac{1}{\pi(Y^*_x | x)} \right]$$
$\mathcal{C}_\pi$ 越小，说明模型生成正确解所需的采样次数越少。基座模型通常具有良好的初始覆盖度（$\mathcal{C}_{\text{base}}$ 较小）。

### 2. 定理 2.1：经典策略优化的覆盖度崩溃下界
作者证明了传统无重置策略优化的致命缺陷：
> **定理 2.1（REINFORCE 的覆盖度崩溃）**：对于任意 $\varepsilon \in (0, 1/64]$，存在一个基座覆盖度极好（$\mathcal{C}_{\text{base}} \le 6$）的强化学习实例，使得在任意学习率 $\alpha \le 1/5$ 及任意静态基座正则化参数 $\eta \in (0, \infty]$ 下，REINFORCE 在达到 $\varepsilon$-最优策略前，必然产生某个中间迭代步 $t$，其覆盖度剧烈膨胀为：
> $$\mathcal{C}_{\pi_t} = \exp\left( \Theta\left(\frac{1}{\sqrt{\varepsilon}}\right) \right), \quad \text{导致收敛步数下界达到 } T = \Omega\left( \frac{\mathcal{C}_{\pi_t}}{\alpha \sqrt{\varepsilon}} \right) \text{ 的指数级灾难。}$$

物理本质在于：Softmax 策略下的 RL 目标具有非凹性（Non-concavity），其梯度范数受限于最优分布覆盖比 $\|\pi^* / \pi_t\|_\infty$。一旦某种次优动作因初期幸运采样占据主导，正确动作概率被挤压至近乎为零，策略梯度即使在非最优点也会彻底衰减消失，形成假死平台期。

### 3. APMD（近似策略镜像下降）元算法
为攻克此难题，APMD 构造了基于动态参考策略的序列化正则目标：
$$\pi^*_{t,\eta} := \arg\max_{\pi} \mathbb{E}_\pi [r(x, y)] - \frac{1}{\eta} D_{\text{KL}}(\pi \parallel \pi_t) \implies \pi^*_{t,\eta}(y|x) \propto \pi_t(y|x) e^{\eta r(x, y)}$$

核心定理保证：
- **覆盖度留存（Coverage-Preserving）**：若每个子问题求解精度满足 $D_{\text{KL}}(\pi_{t+1} \parallel \pi^*_{t,\eta}) \le \varepsilon_{\text{in}} := \frac{1}{64 \mathcal{C}_{\text{base}} T^2 \log(eT)}$，则以极高概率保证：
  $$\pi_t(Y^*_x | x) \ge \frac{1}{2} \pi_{\text{base}}(Y^*_x | x), \quad \forall 0 \le t \le T$$
- **全局次线性收敛**：全局期望奖励的差距以反比于外层步数的速度严格递减：
  $$J^* - J(π_T) \le \frac{\log(2 \mathcal{C}_{\text{base}})}{\eta T}$$

```

  算法流派                核心优化目标与损失函数             KL 参考锚点设定    是否具备覆盖度留存保证？
  ─────────────────────────────────────────────────────────────────────────────────────────────
  经典 REINFORCE          对 J(π) 执行纯策略梯度上升         无                否（指数级崩溃）
  标准静态 PPO / GRPO     相对基座模型的截断重要性采样比     静态固定在 π_base  否（极易陷入长平台期）
  APMD-PPO / APMD-GRPO    包含周期重置的近端优势优化         动态重置至 π_t     是（定理 3.1 严格保证）

## 实验结论与重大理论映射

### 1. 模拟实验对覆盖度动态的严格验证
在 $\mathcal{C}_{\text{base}} = 6$ 的基准环境中对比静态 REINFORCE 与 APMD：
- **静态基座 REINFORCE**：在 1,500 步时，覆盖度指标 $\mathcal{C}_{\pi_t}$ 迅速从 6 剧增到 $10^4$ 以上，模型陷入持续超过 8,000 步的零梯度平台期；
- **APMD（每 $K=100$ 步重置参考策略）**：覆盖度在全过程中稳稳压制在 10 以内，仅耗费 1,200 步便顺利攀升至全局最优解 $J^* = 1.0$，实现了 **8 倍以上的优化收敛加速**。

### 2. 为月之暗面 Kimi k1.5 平方损失 RL 提供严格理论背书
本论文第 4 节的重磅贡献之一，是将 APMD 理论框架直接映射至以 Kimi k1.5 为代表的**平方损失回归策略优化算法**：
$$\mathcal{L}_{\text{square}}(\theta) := \mathbb{E}_{x, y \sim \pi_t} \left[ \left( \log \pi_\theta(y|x) - \log \pi_t(y|x) - \eta A^{\pi_t}(x, y) \right)^2 \right]$$
理论证明：最小化该均方误差回归损失，在数学本质上即是隐式执行了一次以 $\pi_t$ 为参考点的 APMD 镜像下降更新。这从理论上首次解释了**为什么 Kimi 团队抛弃传统 PPO 剪切比率、采用平方损失后，模型的长思维链推理训练稳定性显著提升且绝不发生策略崩溃**。

## 实践启示与工程落地

1. **废弃将 KL 锚定在静态 $\pi_{\text{base}}$ 的过时做法**：在长时间、大规模强化学习训练中，必须引入参考策略的滚动重置机制（Rolling Reference Reset），将 KL 正则的比较基准定期切换为最新的检查点 $\pi_t$。
2. **解锁超强正则化参数**：在以往的静态参考下，工程师不敢大幅调大正则权重；而在引入参考重置后，团队可以大胆加大内层正则强度，使得每个微调步的方差降至极低，保障训练过程平稳如流水。
3. **拥抱平方损失与回归式 RL 范式**：论文为回归式强化学习（如 Kimi k1.5 方案）洗清了“纯经验玄学”的质疑，证明其不仅在工程上易于多卡并行和梯度裁剪，更在理论上天然具备防范覆盖度崩溃的优异数学几何特质。
