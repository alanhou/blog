## The Gap

Autonomous LLM agents improve through self-evolution—extracting reusable skills, reflection logs, and memory traces from repeated trial and error. However, a critical question is routinely neglected: **which task should the agent practice next?**

Existing self-evolving agent frameworks (such as Voyager, Reflexion, and ExpeL) suffer from major curriculum blind spots:
1. **Fixed or Uniform Schedules**: Agents sample practice tasks uniformly at random or follow hardcoded difficulty curricula.
2. **Scalar Progress Metrics**: Methods that attempt active curriculum rely on scalar success rates or scalar loss drops, completely ignoring that complex tasks require distinct combinations of multidimensional skills (e.g., spatial navigation vs. multi-step tool invocation vs. linguistic parsing).
3. **Non-stationarity Dilemma**: As an agent masters sub-skills, the marginal learning value of previously difficult tasks collapses to zero, turning standard bandit algorithms stale.

Without a model that disentangles task difficulty from multidimensional agent proficiencies, training compute is squandered on redundant successes or hopeless failures.

## The Increment

**One sentence**: By modeling an agent's multidimensional skill proficiencies using state-space Multidimensional Item Response Theory (MIRT) and prioritizing tasks with the highest gap-weighted surrogate progress under a non-stationary restart policy, this paper improves terminal task success across six agent benchmarks by up to 13.18 percentage points over uniform practice.

### Core Mechanism

The authors formulate the **SPG-Select** (Surrogate Progress-Guided Selection) framework, consisting of three coordinated stages:

1. **Latent Skill Profiling via MIRT**: Rather than tracking raw success/failure counts, the system infers an agent's latent capability vector $\hat{s}_t \in [0, 1]^K$ across $K$ latent skill dimensions. The probability that an agent with state $s^\star_t$ succeeds on task $\tau$ is governed by a multidimensional logistic link:
   $$p^\star_\tau(s^\star_t) = \text{sigmoid}(a_\tau^{\star\top} s^\star_t - d^\star_\tau)$$
   where $a_\tau \in \mathbb{R}^K$ is the task's discrimination vector (which skills the task demands) and $d_\tau \in \mathbb{R}$ is intrinsic task difficulty.
2. **Gap-Weighted Progress Scoring**: The agent computes its capability gap vector $g_t = 1 - \hat{s}_t$. An encoder predicts the expected proficiency leap $\hat{\Delta}(\tau, \hat{s}_t)$ along each skill axis if task $\tau$ is attempted. The exploitation score is the inner product $g_t^\top \hat{\Delta}(\tau, \hat{s}_t)$, focusing practice where the skill deficit is widest.
3. **SPG-Select-R (Non-stationary Restarting UCB)**: Because the agent's skills evolve over time, past reward distributions become non-stationary. SPG-Select-R constructs Upper Confidence Bound (UCB) scores balancing gap-weighted progress against parameter uncertainty, and periodically wipes bandit statistics at epoch boundaries while preserving accumulated skill memory and profile weights.

**Structural Metaphor**: Think of a decathlete training for the Olympics with a specialized sports scientist. A mediocre coach (uniform practice) makes the athlete run hurdles on Monday, throw the javelin on Tuesday, and high-jump on Wednesday regardless of current weaknesses. A data-driven coach (SPG-Select) maintains a radar chart measuring the athlete's 10 physiological attributes (MIRT profile). Noticing the athlete is already at 95% in sprint speed but lagging at 40% in javelin technique (large gap weight $g_k$), and that practicing javelin drills yields substantial technique gains without risking overtraining injury, the coach prescribes javelin sessions until the gap narrows, periodically recalibrating the radar chart as the athlete gains strength.

### Key Concepts

- **Multidimensional Item Response Theory (MIRT)**: A psychometric framework that models an examinee's binary test outcomes as a function of multiple continuous latent traits ($s$) interacting with item discrimination loadings ($a$) and baseline difficulty ($d$).
- **Surrogate Progress**: The difference $\hat{s}_{t+1} - \hat{s}_t$ between consecutive latent capability vectors, used as an internal learning signal when external task rewards are sparse or delayed.
- **Dynamic Pseudo-Regret in Non-stationary Bandits**: A theoretical measure of decision quality that compares the agent's chosen practice path against the optimal time-varying policy $\tau^\star_t$, bounded by $\tilde{\mathcal{O}}(\sqrt{T \cdot V_T})$ where $V_T$ is the total variation budget of the underlying environment parameters.

## Expert Assessment

- **Problem choice**: High practical significance. LLM agent researchers have poured enormous effort into prompt design, tool retrieval, and reflection memory, while treating task selection as an afterthought. Active curriculum is the true engine of autonomous lifelong learning.
- **Method maturity**: Methodologically creative. Bringing MIRT—a century-old psychometric tool for human standardized testing—into the loop of LLM skill acquisition is an inspired structural insight. A notable unexamined limitation is that MIRT assumes skill requirements across tasks are static linear combinations; in open-ended software engineering or complex multi-agent simulations, task skill requirements may dynamically shift based on intermediate reasoning steps.
- **Experimental integrity**: Thorough verification. Evaluated on both embodied manipulation (ALFWorld) and web navigation (WebShop) across three distinct agent evolution backends (Reflexion, ExpeL, Voyager). SPG-Select-R beats uniform sampling in all six benchmark-backend pairs (averaging +7.2% on ALFWorld, up to +13.18% on ExpeL). The ablation confirms that restarting (SPG-Select-R) outperforms sliding-window tracking (SPG-Select-W).
- **Writing quality**: Rigorous and clear. The theoretical appendix provides full proofs of the dynamic pseudo-regret bounds under non-stationary parameters.
- **Verdict**: **Strong Accept**. A pioneering fusion of psychometrics, multi-armed bandits, and self-evolving agent architectures.

## Takeaways

- **Never train agents on uniform task distributions**: Even modest curriculum steering based on capability deficits yields double-digit percentage gains over uniform practice.
- **Psychometrics translates directly to AI evaluation**: Item response theory separates intrinsic task hardness from model proficiency, providing a cleaner diagnostic than raw success rates.
- **Handle non-stationarity with scheduled resets**: In self-improving agents, old exploration statistics turn toxic because the agent's capability changes; periodic restarts prevent the curriculum optimizer from freezing on yesterday's bottlenecks.

## 缺口

具备自我演化能力的大语言模型智能体（Skill-Evolving LLM Agents）通过与环境交互试错、反思错误日志并沉淀可复用的技能库，展现出持续进化的潜力。
然而，这一领域长期忽视了一个底层决定性问题：**智能体在有限的练习预算下，究竟应该选择练习哪一个任务？**

现有的自演化智能体框架（如 Voyager、Reflexion、ExpeL）在任务调度上存在严重的结构性盲区：
1. **静态均匀抽样**：绝大多数系统采用完全随机均匀抽样，或者按预设难度阶梯推进。
2. **标量进度指标的误导性**：少数尝试主动课程学习的方法仅依赖单一标量的“任务成功率”或“损失下降值”，完全抹平了复杂任务对多维技能组合（如空间导航、多步工具调用、语言语义解析）的差异化需求。
3. **技能演化的非平稳性（Non-stationarity）**：随着智能体技能库的扩充，原先困难任务的边际学习价值迅速衰减为零，导致传统多臂老虎机（Bandits）算法因历史统计量失效而僵死。

缺乏一套能够将任务难度与智能体多维能力解耦的评估体系，导致宝贵的演化计算资源被大量浪费在“已掌握的简单任务”或“能力断层严重的极端任务”上。

## 增量

**一句话**: 本文通过引入状态空间多维项目反应理论（MIRT）实时推断智能体的多维能力向量，并结合周期性重置的老虎机策略（SPG-Select-R）优先调度能力缺口最大的练习任务，在六大主流智能体基准上相较均匀采样取得最高 13.18 个百分点的成功率提升。

### 核心机制

该方法构建了名为 **SPG-Select**（基于替代进度的引导选择）的闭环课程框架，由三个核心模块协同驱动：

1. **基于 MIRT 的潜在能力建模**：不再依赖单次互动的成败计数，而是将智能体在 $K$ 个潜在能力维度的熟练度建模为潜状态 $\hat{s}_t \in [0, 1]^K$。
对于给定任务 $\tau$，智能体的胜率由多维 Logistic 链路决定：
   $$p^\star_\tau(s^\star_t) = \text{sigmoid}(a_\tau^{\star\top} s^\star_t - d^\star_\tau)$$
   其中 $a_\tau \in \mathbb{R}^K$ 为任务的区分度向量（该任务在各项技能上的权重负荷），$d_\tau \in \mathbb{R}$ 为任务的固有绝对难度，完美实现了能力与难度的解耦。
2. **能力缺口加权增益预测**：计算智能体当前的技能缺口向量 $g_t = 1 - \hat{s}_t$。
利用在预热数据上训练的编码器预测尝试任务 $\tau$ 预期带来的技能跃迁 $\hat{\Delta}(\tau, \hat{s}_t)$。
通过内积 $g_t^\top \hat{\Delta}(\tau, \hat{s}_t)$ 形成加权增益，使智能体精准聚焦于自身最薄弱的核心能力板。
3. **非平稳周期重置决策（SPG-Select-R）**：为克服智能体能力不断增强带来的环境非平稳性，SPG-Select-R 构造了融合缺口增益与岭回归不确定性的上置信界（UCB）评分，并在每个演化周期（Epoch）边界主动重置老虎机统计量，同时完好保留累积的记忆、技能库与能力图谱参数。

        |

        |                                       |
        v                                       v

**核喻（十项全能国家队教练的雷达图教学法）**：
将整个过程比作**顶尖田径教练为十项全能运动员定制奥运冲刺集训日程**。
平庸的教练（均匀抽样）机械地排课：周一跑跨栏、周二掷标枪、周三跳高，完全不管运动员当下的体能短板。
而科学教练（SPG-Select）手里攥着一张动态更新的十维雷达图（MIRT 图谱）。
当教练发现运动员的短跑熟练度已达 95%，但标枪投掷技术只有 40%（缺口权重 $g_k$ 极大），且根据运动生理学模型，此时加练标枪能获得巨大的边际技术进阶且不易受伤时，教练便果断安排标枪专项特训，直到该项技能追平短板。
在每个训练周期结束后，教练重新校准基准指标，防止过去的体能数据误导新的训练决策。

### 关键概念

- **多维项目反应理论（Multidimensional Item Response Theory, MIRT）**：心理测量学用于人类标准化考试的经典理论。
它将考生的多维潜质（如数理逻辑、空间想象、语言理解）与题目的多维区分度负荷及难度参数严密解耦。
- **替代性进阶（Surrogate Progress）**：相邻两次推断之间能力向量的差值 $\hat{s}_{t+1} - \hat{s}_t$。
在环境真实稀疏奖励无法即时反馈时，充当智能体内省式的内在驱动信号。
- **非平稳环境下的动态伪遗憾界（Dynamic Pseudo-Regret）**：衡量在线任务选择策略与时变最优基准之间累积差距的理论上界。
论文证明该算法的遗憾上界被参数总变差预算严密控制在 $\tilde{\mathcal{O}}(\sqrt{T \cdot V_T})$ 之内。

- **严禁对自演化智能体做均匀任务投喂**：基于能力画像的主动课程调度无需增加额外的模型参数，就能带来两位数百分比的端到端成功率净增。
