## The Gap

World models (WMs)—neural networks that predict environment transitions given current states and actions—represent a foundational pillar of embodied AI. By enabling **test-time reasoning via Model Predictive Control (MPC)**, world models can synthesize completely novel trajectories for unseen test goals without requiring task-specific policy retraining.

However, planning with world models in complex, multi-step environments faces two catastrophic bottlenecks:

1. **Exponential Search Complexity**:
   - The action-space search budget expands exponentially with the planning horizon ($|\mathcal{A}|^H$). Searching thousands of continuous action sequences over hundreds of steps quickly becomes intractable.
2. **The Compounding Error & "Wormhole" Trap**:
   - Small autoregressive prediction errors compound at each temporal step.
   - Crucially, test-time optimization is **fundamentally adversarial**: an optimizer seeking high-reward trajectories will naturally gravitate toward regions where the learned world model underestimates real-world constraints—discovering hallucinated transitions, teleportations, or physically impossible "wormholes" through obstacles.

Previous hierarchical world models attempted to fix this using pre-trained skills, macro-actions (frame-skipping), or value functions. However, macro-actions sacrifice fine-grained dexterity, while value functions require dense reward coverage that fails to generalize out-of-distribution (OOD).

```
                 THE WORLD MODEL PLANNING DILEMMA

  Single-Level World Model MPC (Raw Actions):
  s_0 ──(a_0)──> s_1 ──(a_1)──> s_2 ──...──> s_T
  - 100-step horizon = 100 autoregressive steps
  - Compounding error explodes: s_T diverges into unphysical hallucinations!
  - Optimizer exploits model error -> finds "wormholes" through obstacles.

  Rigid Macro-Action Hierarchies:
  s_0 ──────[Skill 1: Run]──────> s_10 ──────[Skill 2: Jump]──────> s_20
  - Inflexible: Cannot adjust millimeter-level gripper orientations.
  - Brittle: Fails immediately when encountering unseen obstacle geometries.
```

## The Increment

**One sentence**: ID-WM (Implicit Dynamics World Models) resolves the long-horizon planning crisis by decoupling state-space topological reachability from local control: a diffusion-based high-level generator samples physically feasible neighboring subgoals from a well-behaved Gaussian latent prior, while a low-level world model operates as an inverse dynamics solver to deduce executable motor actions.

```
                               ID-WM ARCHITECTURE

  High-Level Planning (State-Space Manifold Reachability):
  Gaussian Noise z ~ N(0, I) ──┐
  Current State s_t ───────────┼──> [f_hi: Diffusion Model] ──> Subgoal s_{t+Δ}
  Temporal Horizon Δ ──────────┘       (Implicit Dynamics)
                                                │
                                                ▼
  Low-Level Execution (Inverse Dynamics Grounding):
  Subgoal Pair (s_t, s_{t+Δ}) ─┐
                               ├──> [f_lo: Inverse Dynamics] ──> Actions [a_t, ..., a_{t+Δ-1}]
  Local Physics Constraints ───┘
                                                │
                                                ▼
                                    [Environment Execution]
                                 s_t ──a_t──> s_{t+1} ──...──> s_{t+Δ}
```

## The Anatomy

### 1. High-Level Model: Implicit Dynamics via Latent Diffusion

Instead of searching over jagged, high-dimensional sequences of motor commands, ID-WM formulates the high-level world model as a **neighboring state generator**:
$$s_{t+\Delta} = f_{\text{hi}}(s_t, z, \Delta)$$

- $s_t$: Current environment state.
- $\Delta$: Desired temporal abstraction step size (e.g., 10 to 30 timesteps).
- $z \sim \mathcal{N}(0, I)$: A standard Gaussian latent noise vector.

By training $f_{\text{hi}}$ as a conditional diffusion model conditioned on $(s_t, \Delta)$, the unit Gaussian distribution $\mathcal{N}(0, I)$ is mapped smoothly onto the **manifold of physically reachable states within $\Delta$ steps**.

**Why this eliminates wormholes**:
The latent variable $z$ serves as an **implicit high-level action**. Because $z$ is drawn from a smooth, continuous Gaussian prior, test-time optimizers (like Cross-Entropy Method / CEM) sample within a strictly well-behaved distribution $\mathcal{N}(0, I)$. The planner cannot construct arbitrary out-of-distribution hallucinations because the diffusion model projects every sample back to the valid data manifold.

### 2. Low-Level Model: Inverse Dynamics Action Solver

Once a sequence of abstract subgoals $\{s_0, s_\Delta, s_{2\Delta}, \dots, s_T\}$ is synthesized by the high-level planner, the low-level model extracts the actual motor commands:
$$(a_t, \dots, a_{t+\Delta-1}) = f_{\text{lo}}(s_t, s_{t+\Delta})$$

Because $s_{t+\Delta}$ is guaranteed to be within the local reachability radius $\Delta$, the low-level problem reduces to a deterministic local trajectory tracking problem. The inverse dynamics solver solves for executable actions without needing to know global behavioral goals, eliminating error accumulation over long horizons.

### 3. Hierarchical Test-Time Planning

At inference time, given an arbitrary zero-shot goal $s_g$:
1. **High-Level Trajectory Optimization**: The planner searches for a sequence of latent noise vectors $(z_0, z_1, \dots, z_{K-1})$ that minimizes the distance between predicted final state $\hat{s}_{K\Delta}$ and goal $s_g$:
   $$\mathcal{J}(z_{0:K-1}) = \|\hat{s}_{K\Delta} - s_g\|_2$$
   Optimization is performed using CEM over the Gaussian prior.
2. **Interleaved Execution**: The low-level controller executes actions for the first subgoal segment, observes the true environment state, and replans if deviations occur.

## Key Takeaways

1. **Decouple Reachability from Control**: A world model should not attempt to predict every microsecond motor joint position over a 10-second task. The high-level model needs only to answer: *"Where on the state manifold can I safely reach next?"*
2. **Gaussian Noise as Implicit High-Level Actions**: Using standard Gaussian latents $z$ as implicit high-level actions bounds test-time search to a well-behaved distribution, permanently closing the "wormhole" exploit that plagues classical world model MPC.
3. **True Zero-Shot Behavior Synthesis**: By breaking long horizons into locally feasible segments, ID-WM stitches together novel trajectories that were never demonstrated in training, realizing Yann LeCun's vision of autonomous planning via learned world dynamics.

## 核心痛点与背景

基于世界模型（World Models, WMs）的具身智能决策，是实现自主机器人推理与泛化的核心基石。通过在测试期结合模型预测控制（Model Predictive Control, MPC），智能体无需针对每个新任务重新训练策略，即可利用学得的环境物理动态模型针对全新目标自主搜索规划动作。

然而，在面对长时程（Long-Horizon）复杂物理任务时，传统世界模型规划面临两大毁灭性瓶颈：

1. **动作搜索空间呈指数级爆炸**：
   - 规划时间步长 $H$ 越长，连续动作空间的搜索复杂度呈 $|\mathcal{A}|^H$ 指数激增，对数百步微观关节力矩进行全局优化在计算上完全不可行。
2. **复合误差与“物理虫洞”幻觉（Wormhole Exploitation）**：
   - 自回归预测误差会在时间步上迅速累积放大。
   - 更致命的是，**测试期规划优化在数学上是天生具有对抗性的**：优化算法为了寻找高回报路径，会本能地钻世界模型在训练分布边缘的拟合漏洞——发现虚假的“瞬移”、“穿墙”或违背物理定律的“虫洞”，导致实际执行时灾难性失败。

以往的分层世界模型试图通过预训练宏动作技能（Macro-actions）、固定跳帧（Frame-skipping）或价值函数来缓解这一问题。然而，宏动作丧失了毫米级的灵巧抓取控制，而价值函数对密集奖励的高度依赖又使得模型丧失了分布外（OOD）泛化能力。

```
                    传统世界模型长程规划的两难困境

  单层原生动作世界模型 (Single-Level WM with MPC):
  s_0 ──(a_0)──> s_1 ──(a_1)──> s_2 ──...──> s_T
  - 100 步长程任务 = 100 步自回归滚雪球
  - 预测误差雪崩：末端状态 s_T 彻底偏离物理真实流形
  - 规划器利用模型漏洞穿墙，产生“时空虫洞”幻觉！

  刚性技能/宏动作分层 (Rigid Macro-Actions):
  s_0 ──────[预设技能 1: 奔跑]──────> s_10 ──────[预设技能 2: 跳跃]──────> s_20
  - 丧失连续微操精度，无法应对毫米级灵巧操作
  - 泛化极差：遇到未见过的障碍物几何形态直接卡死
```

## 核心技术实现

### 1. 高层世界模型：基于潜变量扩散的隐式动力学

ID-WM 不在高维连续动作空间中盲目搜索，而是将高层世界模型构建为**邻域物理状态生成器**：
$$s_{t+\Delta} = f_{\text{hi}}(s_t, z, \Delta)$$

- $s_t$：当前环境观测状态。
- $\Delta$：时间抽象跨度（例如以 10 至 30 个时间步为一个阶段）。
- $z \sim \mathcal{N}(0, I)$：标准各向同性高斯白噪声。

高层网络 $f_{\text{hi}}$ 采用条件扩散模型（Conditional Diffusion Model）建模。该模型将标准高斯分布 $\mathcal{N}(0, I)$ 平滑映射到**当前状态 $s_t$ 在 $\Delta$ 步内所有物理可达的真实状态流形**上。

**根除“物理虫洞”的核心机制**：
潜变量 $z$ 被视为一个**隐式高层动作（Implicit High-Level Action）**。在测试期，交叉熵规划器（CEM）只需要在光滑、凸优、边界良好的标准高斯分布 $\mathcal{N}(0, I)$ 中采样搜索。由于扩散模型的每一步生成都受数据流形约束，优化器彻底失去了构造不可行超自然轨迹的空间，“时空虫洞”被从根源上封堵。

### 2. 底层世界模型：逆动力学动作解耦求解器

当高层规划器合成了一条抽象子目标链 $\{s_0, s_\Delta, s_{2\Delta}, \dots, s_T\}$ 之后，底层求解器负责解算具体的连续动作输出：
$$(a_t, \dots, a_{t+\Delta-1}) = f_{\text{lo}}(s_t, s_{t+\Delta})$$

由于连续子目标 $s_{t+\Delta}$ 在物理上已被高层模型保证在局部半径 $\Delta$ 内可达，底层求解退化为一个确定性的局部轨迹对齐问题。底层模型完全不需要理解全局长程任务语义，彻底消除了长期自回归带来的误差累积。

### 3. 分层测试期规划流程

在面对任意给定的零样本新目标 $s_g$ 时：
1. **高层隐空间轨迹搜索**：规划器在标准高斯空间中优化采样高斯隐变量序列 $(z_0, z_1, \dots, z_{K-1})$，使得预测的最终状态 $\hat{s}_{K\Delta}$ 与目标 $s_g$ 的欧氏距离最小化：
   $$\mathcal{J}(z_{0:K-1}) = \|\hat{s}_{K\Delta} - s_g\|_2$$
   搜索采用经典的交叉熵方法（CEM），兼具极高的并行效率与收敛稳定性。
2. **交替式执行与重规划（Interleaved MPC）**：底层执行第一段子目标的动作并观测环境真实反馈，若出现外部干扰则以当前状态为起点即时滚动重规划。
