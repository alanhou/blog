## The Gap

Multi-Agent Systems (MAS) powered by collaborating Large Language Models have unlocked unprecedented capabilities in complex planning, formal verification, and distributed problem solving. 

However, virtually all existing systems communicate via **TextMAS (Natural Language Text Messaging)**:
1. **The Verbose Token Tax**: Agents generate thousands of natural language tokens merely to negotiate, summarize, or query intermediate progress. This token tax inflates inference latency and API costs.
2. **The Discretization Information Loss**: Thought processes inside modern Transformers exist as continuous, high-dimensional probability distributions and latent trajectories. Forcing an agent to pass its intermediate thoughts through a discrete `argmax` or temperature-sampled text token string acts as a harsh lossy quantization step.

### Why Prior Latent Communication Failed

Direct **Latent MAS**—passing hidden activation vectors directly between agents—theoretically solves the token tax. But in practice, it faces two insurmountable barriers:
- *The Heterogeneity Wall*: Hidden dimensions ($d_{\text{model}}$) are tightly bound to specific model architectures. A 14B model cannot directly send its 5120-dim hidden states into the 2048-dim layers of a 3B model without complex, brittle projection heads.
- *Static Vectors Lack Intent*: Passing raw hidden states only tells the receiver *what* the sender currently represents, not *which directions matter* or *how the receiver should adjust its own reasoning trajectory*.

```
   THE DUAL FAILURE OF CONVENTIONAL AGENT COMMUNICATION

   1. Text-Based MAS (Standard):
      Agent A [Rich Continuous Latents] ---> [Argmax Discretization] ---> "I think x=3 because..."
                                                                                  |
      Agent B [Must re-read & re-parse 1,000 text tokens from scratch] <----------+
      ===> Severe latency, massive compute waste, loss of intermediate nuances.

   2. Naive Latent MAS:
      Agent A (Qwen-8B, d=4096)  ---> [Raw Vector: 4096 floats] 
                                                    | (Mismatch!)
      Agent B (Qwen-4B, d=2560)  <------------------+ 
      ===> Architectural crash! Cannot ingest foreign hidden dimensions without retraining.
```

## The Increment

**One sentence**: J-Comm establishes a training-free latent communication framework that combines continuous Geometric Agreement for Latent Reasoning (GEAR) with a dimension-agnostic Hidden-and-Jacobian (H+J) interface, enabling heterogeneous LLM agents to exchange continuous directional thoughts across differing model widths without KV-cache sharing.

### Core Mechanism

J-Comm formulates latent agent collaboration through two synchronized mathematical innovations:

1. **GEAR (Geometric Agreement for Latent Reasoning)**:
   - A training-free continuous reasoning module inside the sender agent.
   - Instead of greedily emitting discrete tokens, GEAR reweights candidate tokens over existing embedding manifolds, monotonically optimizing geometric consensus among candidate hypotheses at each intermediate step in continuous embedding space.
2. **The Dual H+J Communication Interface**:
   - Rather than sending raw dimension-locked activations, J-Comm constructs two complementary semantic channels:
     - **The H-Channel (Continuous Hidden State)**: Supplies continuous input representations derived from token feedback distributions, giving the receiver the factual grounding of the sender's hypothesis.
     - **The J-Channel (Jacobian Guidance Lens)**: Computes the first-order sensitivity of the sender's reasoning state projected onto the vocabulary space:
       $$J = \frac{\partial \mathcal{L}_{\text{sender}}}{\partial \mathbf{h}_{\text{sender}}} \in \mathbb{R}^{|\mathcal{V}|}$$
     - *The Genius of Vocabulary Coordinates*: Because the vocabulary space $\mathcal{V}$ is shared across model families (or easily aligned via standard tokenizers), the Jacobian gradient $J$ acts as a universal, model-width-independent coordinate system that conveys *which semantic directions the sender found most sensitive*!
3. **Universal Reconstruction and Prefill Injection**:
   - The Receiver agent receives the H and J signals and reconstructs them using its own native embedding dictionary.
   - It directly injects these directional cues into its own intermediate transformer layers during the prompt prefill phase.
   - Requires **zero KV-cache sharing** and introduces zero additional training parameters.
4. **Empirical Benchmarks**:
   - Tested on heterogeneous agent pairs (e.g., Qwen3-8B communicating directly to Qwen3-4B) across seven standard benchmarks:
     - Achieves 94.80% on MATH-500, 54.55% on GPQA-Diamond, 73.33% on AIME 2024/2025, and 62.93% on ALFWorld.
     - Slashes generated communication tokens by 19.2% to 74.8% while outperforming TextMAS by +1.29 to +8.59 percentage points!

```
   J-COMM H+J LATENT COMMUNICATION ARCHITECTURE

   [Sender Agent: Large Model, e.g. Qwen3-8B]
   - Continuous reasoning via GEAR manifold consensus
   - Extracts:
     1. H-Channel: Continuous hidden state distributions
     2. J-Channel: Vocabulary-indexed Jacobian gradient lens: d(Loss) / d(h)
                         |
                         | [Vocabulary-Indexed Coordinate Space: No dim mismatch!]
                         v
   [Receiver Agent: Smaller Model, e.g. Qwen3-4B]
   - Reconstructs H and J cues through native embedding dictionary
   - Injects directional guidance directly into intermediate layers during Prefill
                         |
                         v
   [Ultra-Fast, High-Precision Downstream Output]
   - Up to 74.8% fewer tokens generated
   - Direct mathematical consensus without verbose text chats!
```

### Key Concepts

- **Geometric Agreement for Latent Reasoning (GEAR)**: An optimization protocol that seeks continuous geometric alignment among multiple candidate hypotheses within token embedding space.
- **Jacobian Lens**: The projection of intermediate hidden-state gradient sensitivity onto vocabulary coordinates, representing functional reasoning momentum independently of model width.
- **Prefill Injection**: The technique of modulating intermediate transformer layer activations during the initial prompt encoding phase rather than through sequential autoregressive generation.

## 核心困境

以多智能体系统（Multi-Agent Systems, MAS）为代表的分布式协作网络，在复杂代码工程、高难数理竞赛与智能体长程规划中展现出惊人的生产力。

然而，几乎所有现存的多智能体框架都依赖**自然语言文本消息（TextMAS）**进行交互：
1. **沉重的 Token 税（Token Tax）**：智能体之间为了商讨方案、同步中间结论，必须生成成百上千个文本词元。巨大的 Token 消耗不仅急剧拉长推断耗时，更带来了昂贵的算力账单。
2. **离散采样的信息折损**：大语言模型内部的思考本质上是连续高维流形上的潜状态轨迹。强制智能体通过 `argmax` 或温度采样将其截断为离散文字串，相当于施加了极其粗暴的降维有损压缩，大量微妙的中间不确定性与置信度先验在文本化瞬间荡然无存。

### 为什么以往的潜空间连续通信（Latent MAS）难以落地？

直接在智能体之间传递 Transformer 的连续隐层激活向量（Hidden States），理论上能够彻底免除文本生成的计算开销。但工业界长期面临两大技术天堑：
- **模型异构性之墙（The Heterogeneity Wall）**：隐层维度（$d_{\text{model}}$）高度绑定特定模型。例如，Qwen-8B 的隐层是 4096 维，而 Qwen-4B 是 2560 维；由于维度不匹配且未经跨模型联合训练，小模型根本无法直接读取大模型的隐状态。
- **静态向量缺乏引导性（Lack of Functional Guidance）**：仅传递静态的隐藏向量，接收端只能看到发送端「当前算出了什么」，却无法感知「哪些特征对最终目标最关键」以及「下游思考应该往哪个方向演进」。

```
   传统多智能体协作通信的两大核心痛点

   1. 传统自然语言文本通信 (TextMAS):
      智能体 A [丰富连续思考流] ---> [离散词表采样] ---> "我认为答案应该在区间 [3, 5]..."
                                                              |
      智能体 B [必须逐字重新解析这数百个字符] <---------------------+
      ===> 生成时延高，算力浪费严重，中间思考的微妙置信度被截断！

   2. 朴素潜层向量通信 (Naive Latent MAS):
      智能体 A (Qwen-8B, 隐层 4096 维)  ---> [抛出 4096 维浮点数组]
                                                    | (维度根本对不上!)
      智能体 B (Qwen-4B, 隐层 2560 维)  <-----------+
      ===> 架构不兼容！缺乏重训映射层时，异构模型之间完全无法识别！
```

## 核心增量

**一句话定位**：J-Comm 提出了一种完全无需微调的跨智能体连续潜空间通信框架，通过隐空间几何共识机制（GEAR）驱动自演化思考，并首创基于词表空间投影的「隐藏状态 + 雅可比导数（H+J）」双通道接口，彻底打破了不同参数尺寸大模型之间的维度壁垒，在无需共享 KV Cache 的前提下削减高达 75% 的通信 Token 消耗，且全面提升推理胜率。

### 核心机制拆解

J-Comm 从底层数学几何出发，解构了连续多智能体协作的交互界面：

1. **隐空间几何共识机制（GEAR, Geometric Agreement for Latent Reasoning）**：
   - 发送端模型内部的免微调连续推理引擎。
   - 彻底摒弃贪婪采样离散词元的方式，GEAR 在模型的原生嵌入空间中对候选词元进行权重动态重构，在每一步单调优化候选假设在向量流形上的几何共识度，维持连续思考的纯粹性。
2. **独特的 H+J（隐藏状态 + 雅可比导数）双通道接口**：
   - 为彻底解绑模型内部隐藏维度对通信的限制，J-Comm 创新性地构建了双通道语义协议：
     - **H 通道（连续隐状态流）**：基于词元反馈分布提供丰富的连续潜变量表征，为接收端提供坚实的事实与假设支撑（Content）。
     - **J 通道（雅可比引导透镜）**：计算发送端思考状态相对于目标损失的敏感度雅可比梯度，并投影到**词表坐标系（Vocabulary Coordinates）**：
       $$J = \frac{\partial \mathcal{L}_{\text{sender}}}{\partial \mathbf{h}_{\text{sender}}} \in \mathbb{R}^{|\mathcal{V}|}$$
     - *词表坐标系的工程绝妙之处*：无论模型隐藏层是 4096 维还是 2560 维，同一模型家族的词表（Vocabulary）空间都是一致的！通过词表作为通用度量基底，J 通道无需任何跨模型对齐训练，就能跨模型无损传递「当前思考对哪些语义方向最敏感」的高阶导数动量（Directional Intent）！
3. **通用词典重建与预填充层（Prefill）无感注入**：
   - 接收端智能体收到 H 与 J 信号后，利用自身原生词嵌入词典快速解码还原。
   - 在接收端的 Prompt 预填充（Prefill）阶段，直接将该引导信号无缝注入指定的中间隐藏层。
   - **完全不需要共享显存开销巨大的 KV Cache**，也不增加任何额外的可学习参数。
4. **数理基准全线突破**：
   - 在 Qwen3-8B 引导 Qwen3-4B 的异构智能体实测中，横扫 7 大严苛数理与规划基准：
     - 在 MATH-500 达到 94.80%，GPQA-Diamond 达到 54.55%，AIME 2024/2025 达到 73.33%，ALFWorld 达到 62.93%。
     - 相比传统文本通信（TextMAS），通信生成的文本 Token 数量**大幅骤降 19.2% 至 74.8%**，且解题绝对准确率提升 1.29 到 8.59 个百分点！

```
   J-COMM 雅可比引导潜空间通信流程全景

   [发送端智能体: 大模型，例如 Qwen3-8B]
   - 借助 GEAR 机制在连续嵌入流形中单调优化思考假设
   - 抽取两大信息通道:
     1. H 通道: 包含丰富连续上下文假设的潜状态分布
     2. J 通道: 词表对齐的雅可比动量透镜 d(Loss) / d(h)
                         |
                         | [词表坐标系统一表示：彻底打破 4096 维 vs 2560 维几何壁垒!]
                         v
   [接收端智能体: 轻量模型，例如 Qwen3-4B]
   - 借助自身词嵌入矩阵迅速解算 H 与 J 引导信息
   - 在 Prefill 阶段直接注入中间 Transformer 隐层
                         |
                         v
   [极速、高准确率终局输出]
   - 削减高达 74.8% 的无效自然语言客套废话
   - 连续潜空间梯度共振，准确率全面碾压传统文本对话！
```

### 关键概念

- **隐空间几何共识（GEAR）**：在无参数微调的前提下，通过对词嵌入流形上的候选向量进行连续重加权，单调最大化推演假设自洽性的思考方式。
- **雅可比引导透镜（Jacobian Lens）**：将模型中间隐层的梯度敏感性投影至全局词表坐标系，用于表征具有确定性推理方向的跨模型通用动量。
- **预填充注入（Prefill Injection）**：在接收端处理初始上下文的阶段将外部潜特征直接并入指定网络层，无需经历逐字生成的慢速解码过程。
