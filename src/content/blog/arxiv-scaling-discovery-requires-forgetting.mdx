## The Gap

Automated scientific discovery and iterative engineering optimization powered by LLM agents (such as automated kernel optimization, heuristic algorithm design, and neural architecture search) have emerged as premier frontiers of agentic AI. When practitioners seek to scale discovery compute, they standardly pursue three complementary axes:

1. **Depth Scaling**: Allowing a single agent to iterate across longer horizons (50+ turns).
2. **Width Scaling**: Running independent agent threads in parallel.
3. **Communication Scaling**: Enabling parallel agents to share insights and build upon one another's intermediate candidates.

However, all three scaling strategies inevitably hit a **hard empirical wall**: as agents accumulate conversational history and experiment logs, marginal returns rapidly drop to zero. The authors diagnose the underlying cognitive mechanism: **historical anchoring**. 

As context windows fill with dozens of prior failures and minor tweaks, the model's attention is captured by its own historical trajectories. Instead of entertaining daring conceptual pivots, the agent makes timid, incremental modifications around previously explored code blocks. More compute budget merely produces more tokens of repetitive self-rationalization inside local minima.

```
   THE COGNITIVE ANCHORING TRAP IN EXTENDED AGENT SEARCH

   Turn 1-5: Bold initial exploration -> Finds decent Candidate A
         |
   Turn 6-25 (Accumulating Scratchpad Clutter):
   Context: [Candidate A, Fail 1, Fail 2, Patch 1, Fail 3, Micro-tweak 4...]
         |
         v
   Attention Bias: Agent's priors get anchored to Candidate A's structure
   Action: Produces minuscule, conservative tweaks; fears breaking existing code
         |
         v
   Turn 26-50: Zero progress! Adding compute budget yields flat plateau.
         |
         v
   SOLUTION: FORCED PERIODIC AMNESIA (FORGETTING)
   1. Keep only the highest-scoring candidate artifact on disk
   2. Completely wipe all conversation history, failed traces, and agent memory
   3. Re-spawn agents with a clean context, evaluating the candidate from scratch!
```

## The Increment

**One sentence**: The authors show that scaling automated research requires periodically wiping agents' accumulated conversation history and search traces, retaining only the global best candidate to break cognitive anchoring—delivering up to 39% improvement over single agents and 15% over communicating swarms under identical compute budgets.

### Core Mechanism

The authors formalize the **Periodic Amnesia Search (PAS)** protocol for agentic discovery:

1. **The Anchoring Measurement**:
   - Behavioral analysis reveals that as context length grows, the edit distance (Levenshtein distance) between successive proposed code artifacts drops exponentially.
   - The token entropy of proposed diffs collapses, indicating that the LLM is mimicking its recent conversational turns rather than sampling from its broad pre-training prior.
2. **The Forgetting Operator ($\mathcal{F}$)**:
   - Search proceeds in phases of $K$ iterations.
   - At the conclusion of each phase, a pruning operator $\mathcal{F}$ unconditionally discards the entire interactive scratchpad, tool call history, intermediate error messages, and failed attempts.
   - Only the physical artifact that achieved the highest verified score ($c^* = \arg\max_{c} \text{Score}(c)$) is retained.
3. **Clean-Slate Re-initialization**:
   - A fresh team of agents is instantiated. The artifact $c^*$ is presented as a clean, stand-alone specification without any historical baggage explaining *how* it was constructed or what failed previously.
   - Freed from contextual bias, the agents inspect $c^*$ with fresh attention distributions, immediately unleashing high-variance structural innovations that navigate past local optima.
4. **Empirical Benchmarks Across Four Domains**:
   - Validated across: (1) Heuristic algorithm programming, (2) GPU CUDA kernel optimization, (3) Model hyperparameter and training recipe search, and (4) Symbolic reasoning.
   - Yields up to **39% improvement** over continuous long-context agents and **15% improvement** over communicating multi-agent swarms.

```
   PERIODIC AMNESIA SEARCH (PAS) LIFECYCLE

   [Phase 1: High-Variance Exploration]
   Clean Agent Swarm ---> Generates Candidates c_1, c_2, ..., c_k
                              |
                              v
   Verified Best Candidate Found: c* (Score: 78.4)
   Accumulated Context: 45,000 tokens of clutter & failed dead-ends
                              |
                              v
   +-----------------------------------------------------------+
   | THE FORGETTING ACTUATOR                                   |
   | - DISCARD: 45k tokens of chat logs, reasoning, and errors |
   | - RETAIN: Pure artifact code of c* ONLY                   |
   +-----------------------------------------------------------+
                              |
                              v
   [Phase 2: Fresh-Slate Reboot]
   New Agents receive ONLY c* as baseline prompt: "Optimize this code"
   Attention is pristine; bold structural modifications resume!
   ===> Rapidly breaks through to Score 92.1!
```

### Key Concepts

- **Cognitive Anchoring in LLMs**: The tendency of autoregressive language models to condition heavily on recent in-context tokens, causing generation entropy and conceptual diversity to shrink as history grows.
- **Search Satiation**: The state in agentic exploration where additional compute budget ceases to generate distinct search trajectories due to context window saturation.
- **State-Free Restart**: An optimization strategy that strips away historical search trajectory metadata, retaining only the objective state of the best discovered candidate.

## Framework Shift

```
Before (Memory-Accumulating Agent Architectures):
  Dogma: "More context and memory is always better; never lose past learnings."
  Mechanism: Endless scratchpads, persistent memory vector stores, full chat histories.
  Failure Mode: Rapid stagnation; agents get paralyzed by past failed attempts.

After (Periodic Forgetting Architecture):
  Insight: For open-ended discovery, what an agent forgets is as vital as what it remembers.
  Mechanism: Periodically discard interaction logs and reboot from the single best candidate.
  Results: Unblocks search plateaus; +39% optimization gains under identical token budgets.
```

## Expert Assessment

**Problem choice**: Profound and counter-intuitive. In an era obsessed with infinite context windows and lifelong memory stores, demonstrating that memory acts as an anchor that kills open-ended discovery is a breath of fresh air.

**Method maturity**: Elegant, minimalist, and universally applicable. It requires no complex fine-tuning or specialized vector databases—just a clean bash/python reset loop.

**Experimental integrity**: Tested across four diverse and technically demanding engineering domains (including real GPU kernel optimization where performance cannot be faked).

**Writing quality**: Lucid, philosophically compelling, and supported by rigorous quantitative metrics tracking code edit distances over time.

**Verdict**: **strong accept** — An essential design principle for anyone building autonomous coding, optimization, or scientific research agents.

## Takeaways

- Stop feeding endless conversation history to autonomous research agents; cognitive anchoring cripples exploratory reasoning.
- Implement periodic forgetting: strip chat history every 5-10 iterations and re-prompt from the bare best candidate artifact.
- Evaluate agent search diversity not just by benchmark score, but by tracking the structural edit distance of generated solutions over time.

## 缺口

利用大模型智能体（LLM Agents）进行自主科学发现与工程演进（例如 GPU Triton/CUDA 算子调优、启发式算法设计、神经网络架构探索），已成为前沿 AI 生产力落地的核心战场。
当工程师希望通过堆叠算力预算来换取更优异的探索发现时，业界通常有三条标准路线：

1. **纵向深挖（Depth）**：让单个智能体进行长达几十轮的自主反思与长程迭代。
2. **横向并行（Width）**：启动多个平行的独立智能体分头探索。
3. **集群协同（Communication）**：让多个并行智能体实时交流、共享彼此的中间代码方案。

然而，令人沮丧的是：**这三条看似合理的扩缩容路径，最终无一例外都会迅速撞上难以逾越的「探索死墙」**。
研究团队深入分析了智能体的上下文轨迹，精准定位了背后的心理学与统计学病灶——**历史锚定效应（Cognitive Anchoring）**。

随着探索的推进，上下文窗口中堆满了过往数十轮的失败日志、试错反思与微调痕迹。自注意力机制会不可避免地被这些既有文本深深锁死。智能体开始变得「瞻前顾后」、「谨小慎微」：它不再敢于提出颠覆性的重构构想，而是在已被证明平庸的旧代码局部修修补补。此时投入再多的 Token 与算力，也只是在局部极小值（Local Minima）中反复原地打转。

```
   长程智能体搜索中的「历史记忆枷锁」

   第 1-5 轮：思维活跃，敢打敢拼 ---> 摸索出基准候选方案 A
         |
   第 6-25 轮（上下文充斥海量试错与纠错日志）：
   Prompt 长度激增：[方案 A + 报错 1 + 修正 1 + 报错 2 + 局部打补丁 3...]
         |
         v
   自注意力被既有代码死死锚定：
   智能体变得极度保守，不敢触碰既有架构，只敢改改循环变量
         |
         v
   第 26-50 轮：探索彻底陷入停滞！继续追加 Token 预算收益为零！
         |
         v
   破局解法：强制周期性全面失忆（Forgetting）
   1. 仅在磁盘保留得分最高的代码工件（Artifact）
   2. 物理清空所有对话上下文、工具调用痕迹与反思日志
   3. 以全新白纸状态加载该最佳工件，重新唤醒激进探索！
```

## 增量

**一句话**: 本文提出了「周期性遗忘搜索（Periodic Amnesia Search）」范式，证明了在自主科学发现中，周期性地彻底抹去智能体的对话历史与探索痕迹、仅保留当前全局最佳候选工件重新启程，能够彻底打破思维锚定，在同等算力预算下将发现能力大幅提升 39%。

### 核心机制

研究团队构建了严谨的**「周期性遗忘搜索（Periodic Amnesia Search, PAS）」**闭环机制：

1. **思维锚定与编辑距离坍塌定量证明**：
   - 团队监测了智能体连续生成的代码之间的编辑距离（Levenshtein Distance）。数据表明：随着上下文历史的拉长，代码演化的编辑距离呈现指数级萎缩，Token 生成熵断崖式下滑——智能体退化为复读自己前几轮行为的保守官僚。
2. **遗忘算子（The Forgetting Operator $\mathcal{F}$）**：
   - 算法将连续搜索切分为固定步长（如每 $K$ 轮）的探索阶段。
   - 在一个阶段结束时，遗忘算子 $\mathcal{F}$ 强行执行「内存斩断」：完全丢弃数万 Token 的交互式上下文、反思日志、环境报错以及中间失败草稿。
   - 全局仅筛选保留在物理验证器（如运行效率、测试用例通过率）上得分最高的单一工件：$c^* = \arg\max_{c} \text{Score}(c)$。
3. **白纸重生（Clean-Slate Reboot）**：
   - 系统唤醒一组全新的智能体实例，直接将工件 $c^*$ 作为初始 Prompt 输入：「这是当前的代码，请对其进行极致优化」。
   - 由于新智能体完全不知道这份代码此前是如何被折腾出来的、也不知道曾经出现过什么报错，其注意力分布重回基座预训练的广阔概率流形，立刻迸发出充满想象力的大跨度重构，瞬间跳出旧团队陷入的死胡同。
4. **横跨四大硬核工程领域的全面验证**：
   - 在（1）启发式算法开发、（2）高性能 GPU CUDA 算子调优、（3）神经网络训练超参挖掘、（4）符号逻辑求解等四大任务中全面实证。
   - 相比于无遗忘的长程单智能体，性能最高提升达 **39%**；即便对比具备复杂交流机制的多智能体集群，遗忘机制依然能带来高达 **15%** 的绝对净收益。

```
   周期性遗忘搜索 (PAS) 演进生命周期图

   [第一阶段：高方差开拓]
   全新智能体集群 ---> 自由探索方案 c_1, c_2, ..., c_k
                              |
                              v
   验证器评测出阶段最佳方案：c*（得分：78.4）
   但此时上下文已堆积 45,000 Token 的纠错废话与思维包袱
                              |
                              v
   +-----------------------------------------------------------+
   | 强制遗忘执行器（Forgetting Actuator）                     |
   | - 彻底丢弃：45k Token 的报错、反思、争论与交互记录        |
   | - 唯一留存：方案 c* 的纯净代码文件                        |
   +-----------------------------------------------------------+
                              |
                              v
   [第二阶段：白纸重生]
   全新智能体仅接收 c* 代码：「请将其性能推向极限」
   摆脱历史包袱，激进的大跨度架构创新重新爆发！
   ===> 轻松击穿原有天花板，得分飙升至 92.1！
```

### 关键概念

- **大模型认知锚定（Cognitive Anchoring）**：自回归模型过度受制于 Prompt 中最近的既有内容，导致生成文本的创新方差随上下文变长而急剧萎缩的统计现象。
- **搜索饱和（Search Satiation）**：智能体在探索过程中由于上下文累积过多，继续追加计算预算也无法产出新颖探索路径的停滞状态。
- **状态剥离重启（State-Free Restart）**：剥离所有过程性试错轨迹，仅将最终客观产物作为全新探索起点的极简优化机制。

## 行囊 (Takeaways)

- 永远不要让负责创新探索的代码智能体背着沉重的全量历史上下文；过多的历史记忆会直接抹杀模型的发散思维。
- 在构建科研与算法调优 Agent 时，务必内置周期性遗忘机制：每隔 5 到 10 轮便斩断会话，仅提取最优代码重新发问。
- 衡量智能体探索活力的核心指标不仅是任务得分，更应密切监测其输出代码的编辑距离；一旦编辑距离趋近于零，即为触发遗忘的明确信号。
