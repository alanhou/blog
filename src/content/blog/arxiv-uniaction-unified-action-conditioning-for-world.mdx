## The Gap

Video world models predict future visual frames conditioned on past visual contexts and incoming control actions. To serve as scalable simulators for embodied robotics, autonomous driving, and interactive gaming, these models must be steerable by actions.

However, existing action-conditioned world models suffer from a fundamental architectural fragmentation:

1. **Heterogeneous Action Modalities**: Real-world actions span completely disparate mathematical spaces:
   - *Camera Control*: 6-DoF extrinsic matrices $[R | t]$, field of view, and optical center trajectories.
   - *Robotic Manipulation*: Gripper 3D positions, Euler angles/quaternions, joint torques, and binary gripper states.
   - *Hand Manipulation*: 21-keypoint kinematic skeletons, finger articulation angles.
   - *Physical Interactions*: Continuous directional force vectors applied at arbitrary 3D surface contact points.
2. **Siloed, Single-Action Architectures**: Prior models (such as DriveDreamer, RoboDreamer, or CameraCtrl) design specialized conditioning modules for a single action type. A camera-conditioned model cannot process gripper motions, and a robot policy simulator cannot accept physical pushes or novel view camera trajectories.
3. **Data Fragmentation and Zero Cross-Transfer**: Action-annotated video datasets are exceptionally rare and expensive to gather. Forcing each action type into an isolated model divides this scarce data pool, preventing world models from benefiting from unified scaling laws across physical domains.

## The Increment

**One sentence**: UniAction introduces a universal action-conditioning representation that decomposes arbitrary physical control signals into sparse sets of discrete-semantic and continuous-spatiotemporal action elements mapped directly into the video model's native coordinate space, enabling a single unified model to outperform action-specific expert models.

### Core Mechanism

UniAction establishes a unified coordinate and attention formulation that handles any physical control signal:

1. **Sparse Action Elements Formulation**:
   - Rather than encoding entire action vectors via domain-specific MLPs, UniAction represents any action $A$ as a set of $M$ discrete action elements:
     $$A = \left\{ (\text{id}_m, \mathbf{c}_m) \right\}_{m=1}^M$$
   - $\text{id}_m \in \mathcal{V}_{\text{action}}$: A discrete semantic identity token designating what the element is (e.g., `camera_center`, `left_finger_tip`, `push_force_origin`).
   - $\mathbf{c}_m = (x_m, y_m, z_m, t_m)$: A continuous spatiotemporal coordinate anchoring where and when the action element operates in the physical 3D world over time.
2. **Native Positional Space Grounding**:
   - Instead of projecting actions through disparate auxiliary encoders, UniAction embeds the continuous coordinate $\mathbf{c}_m$ directly into the pretrained video diffusion model's native 3D/4D positional embedding space (e.g., 3D RoPE or learned spatiotemporal grids).
   - This places action elements into the exact same metric coordinate frame as the latent video tokens, allowing self-attention layers to seamlessly correlate visual patch features with spatial action targets.
3. **Cardinality-Calibrated Cross-Attention**:
   - Different action modalities possess wildly different element counts: a global camera trajectory or force push has 1 to 2 elements per frame, whereas two articulated hands have 42 elements.
   - Standard cross-attention softmax exhibits severe cardinality bias, where high-element actions dominate attention weights while low-element actions are ignored.
   - UniAction introduces **cardinality-calibrated attention**, normalizing the cross-attention logits by the modality element count $M$, ensuring invariant conditioning strength regardless of action granularity.
4. **Joint Cross-Modality Synergy**:
   - Trained across four representative action forms: 3D force vectors, camera control, human hand poses, and robotic arm trajectories.
   - A single jointly-trained UniAction model consistently beats four separate action-specific expert baselines on action-following precision (FVD, PSNR, LPIPS), confirming that cross-action joint training creates positive physical transfer.

### Key Concepts

- **Sparse Action Elements**: A modular representation that reduces arbitrary continuous control signals into sets of semantic IDs and spatiotemporal coordinates.
- **Native Positional Grounding**: Aligning action tokens directly into the existing spatiotemporal coordinate system of a vision model, avoiding separate metric translation heads.
- **Cardinality-Calibrated Attention**: An attention scaling technique that prevents cross-attention weights from being skewed by the varying number of discrete tokens in different action modalities.

## Takeaways

- Do not engineer separate network architectures for different control signals; all physical actions can be decomposed into spatiotemporally grounded semantic elements.
- Always calibrate cross-attention when conditioning on modalities with variable token cardinalities to avoid attention dilution or saturation.
- Jointly training world models across diverse action modalities produces positive transfer, beating models trained solely on narrow single-action datasets.

## 核心困境

视频世界模型（Video World Models）旨在根据历史观测与未来的动作指令，推演物理世界随时间演变的动态画面。为了真正成为赋能具身机器人训练、自动驾驶推演与实时交互式仿真沙盒的核心基石，世界模型必须具备精准受控于外部「动作（Action）」的能力。

然而，现存的动作条件化世界模型却深陷严重的体系割裂与数据孤岛困境：

1. **物理动作维度的极大异构性**：现实世界中驱动场景变化的动作信号分布在截然不同的数学空间中：
   - *相机视角控制*：6 自由度外参变换矩阵 $[R | t]$、视场角（FOV）与焦距。
   - *机械臂操纵*：夹爪 3D 坐标、欧拉角/四元数旋转、关节力矩及开合离散信号。
   - *灵巧手交互*：包含 21 个骨骼关键点的运动学拓扑树与手指关节角。
   - *外力碰撞仿真*：施加在任意 3D 物体表面接触点上的连续三维冲量与受力矢量。
2. **各自为政的专用模型烟囱**：现有的条件化方案（如 CameraCtrl、RoboDreamer、DriveDreamer）往往针对单一动作类型设计专有 MLP 投影头。相机控制模型完全无法解析机械臂轨迹，机械臂模型亦无法处理外力碰撞或移动机位变化。
3. **标注数据的灾难性碎片化**：带有精准物理动作标注的视频数据极其稀缺昂贵。由于缺乏统一动作接入范式，宝贵的训练数据被分割在相互孤立的专用子模型中，彻底阻断了世界模型在动作维度上的规模化扩展规律（Scaling Laws）。

## 核心增量

**一句话定位**：斯坦福大学吴佳俊团队提出了通用的世界模型动作条件化框架 UniAction，将任意物理控制信号解构为由离散语义标识与连续时空锚定坐标构成的稀疏动作元，并直接映射至视频模型的原生位置空间；配合基数校准注意力机制，首次实现单一通用模型在多种动作控制能力上全面超越各专用专家模型。

### 核心机制拆解

UniAction 从底层重构了动作信号与视频扩散潜特征之间的坐标对齐与注意力交互机制：

1. **稀疏动作元（Sparse Action Elements）统一表征**：
   - 摒弃以往为不同维度动作定制专有特征提取头的做法，UniAction 将任意动作 $A$ 统一表达为包含 $M$ 个离散动作元的集合：
     $$A = \left\{ (\text{id}_m, \mathbf{c}_m) \right\}_{m=1}^M$$
   - $\text{id}_m \in \mathcal{V}_{\text{action}}$：离散语义标识符，明确动作元的物理归属（如 `camera_center` 相机中心、`gripper_tip` 夹爪末端、`contact_force` 受力点）。
   - $\mathbf{c}_m = (x_m, y_m, z_m, t_m)$：连续时空坐标，将该动作元精确锚定在物理世界的三维空间与时间轴上。
2. **直接映射至视频模型原生位置空间**：
   - 不再引入复杂的多层感知机（MLP）进行跨模态映射，而是直接将连续时空坐标 $\mathbf{c}_m$ 投影至预训练视频扩散模型（如 DiT）的原生 3D/4D 位置编码空间（如 3D RoPE 或时空网格编码）。
   - 动作元与视频潜变量 Patch 在底层的几何度量坐标系中自然对齐，使注意力层能够直接计算视觉特征与动作作用点之间的物理空间相关度。
3. **基数校准交叉注意力（Cardinality-Calibrated Attention）**：
   - 不同动作类型的动作元数量（基数 Cardinality）差异悬殊：相机轨迹或外力冲击每帧通常仅有 1 到 2 个动作元，而双手机构关键点可多达 42 个。
   - 传统交叉注意力中的 Softmax 计算会导致高基数动作严重稀释或低基数动作被忽视。
   - UniAction 提出了基数校准注意力机制，依据该动作模态的实际动作元数量 $M$ 对注意力 logits 进行归一化补偿，确保无论动作粒度粗细，条件化约束强度始终恒定可控。
4. **多模态动作联合训练的正向协同**：
   - 覆盖四种典型物理动作：连续外力冲量、全自由度相机漫游、高自由度人手姿势与多关节机械臂。
   - 严谨的对比评测显示：一个在四类动作数据上联合训练的 UniAction 单一模型，其控制精度与生成画质（FVD、PSNR、LPIPS）全面战胜了针对单一动作分别训练的四个专用专家模型，证明异构动作数据在统一表征下存在显著的正向动力学迁移！

### 关键概念

- **稀疏动作元（Sparse Action Elements）**：将连续与离散的复杂控制信号统一拆解为「语义标识 + 连续时空坐标」的标准元组表示法。
- **原生位置锚定（Native Positional Grounding）**：直接利用视觉扩散模型底层的时空几何位置编码承载动作信息，避免引入额外几何变换黑盒。
- **基数校准注意力（Cardinality-Calibrated Attention）**：通过对动作序列长度进行数学尺度补偿，消除不同动作模态因 token 数量差异带来的注意力偏置。
